# HoloFlow Services

Local Python sidecar that exposes the installed scientific stack as HTTP endpoints for the HoloFlow Mesh Studio web app.

**Why:** The browser can't run trimesh, open3d, aubio, lithophane, or the heavy mesh tools natively. Pyodide can run some of it but slowly. This sidecar gives the React app a fast Python backend it can call over HTTP.

## Endpoints

| Method | Path | What |
|---|---|---|
| GET | `/status` | Capability probe — what's importable |
| GET | `/tools` | Registered tool list with metadata |
| POST | `/lithophane` | Image → relief STL |
| POST | `/mesh/voxelize` | STL/GLB → voxel grid + JSON metadata |
| POST | `/mesh/repair` | STL → watertight STL |
| POST | `/image/segment-bg` | Image → foreground mask |
| POST | `/image/extract-trails` | Image → light trail polylines |
| POST | `/audio/beats` | Audio → BPM + beat timestamps |
| POST | `/image/raw-decode` | RAW camera file → PNG |
| GET | `/capture/list` | List recent captures in `D:\HoloFlow\projects` |
| GET | `/firmware/pov` | List POV firmware projects |
| GET | `/file/{name}` | Download a temp file generated by a previous call |

## First-time setup

```powershell
cd D:\The_Hangar\engines\holoflow-services
pip install -r requirements.txt
```

(All the heavy deps — trimesh, open3d, opencv-python, mediapipe, aubio, lithophane, etc — are already installed system-wide. This only pulls fastapi + uvicorn.)

## Start

```powershell
.\start.bat
```

Or manually:

```powershell
python -m uvicorn main:app --host 127.0.0.1 --port 8765 --reload
```

## Verify

```powershell
curl http://127.0.0.1:8765/status
```

You should see a JSON response with `capabilities` showing each library as `true`/`false`.

## How the web app uses it

The web app (port 5138) makes CORS-allowed fetches to `http://127.0.0.1:8765`. See `src/compute/services.ts` for the TypeScript client. The Toolbox tab in the app polls `/status` and `/tools` to show what's available.

## Adding a new tool

1. Add a `_probe()` call at the top of `main.py` for your new dependency.
2. Write a new `@app.post("/your-tool")` endpoint.
3. Add metadata to the `/tools` list.
4. In `src/compute/services.ts`, add a TypeScript wrapper.
5. In `src/features/toolbox/Toolbox.tsx`, the new tool will show automatically once `/tools` returns it — add a custom "Run" button there if needed.
