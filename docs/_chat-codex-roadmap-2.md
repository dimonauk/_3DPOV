## How to add each in Shopify (repeat × 5)

1. Admin → Products → **Add product**.
2. Paste **Title**, **Description** above.
3. Drag the image into **Media** (use the highest-resolution file you have — Shopify serves downscaled variants automatically).
4. **Pricing**: set to the A3 Photo Rag price; real prices go on variants.
5. **Variants**: add option `Paper and size`, fill in the three rows with prices from the list.
6. **Inventory**: untick "Track quantity" (edition caps are enforced by the edition-number line in the description and by you manually marking "Sold out" when an edition closes — Shopify's inventory system doesn't handle artist editions well).
7. **Tags**: paste the tags from the listing.
8. **Status**: Active.
9. **Publishing**: tick **Online Store** and **Holo-Flow Web**.
10. **Product organization → Collections**: the `Photographs` collection auto-picks it up via the `photo-print` tag, nothing to do here.
11. **Save.**

Once the first product is live and looks right in the Shopify admin, the other four are faster because you'll be on autopilot.
