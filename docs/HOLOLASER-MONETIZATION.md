# HoloLaser / Neo London — Monetization Roadmap

See docs/COMMERCE_ROADMAP.md for the site-wide commerce picture. This
covers the laser/performance work specifically.

## Phase 1 — Sell the performance (near-term, ~0 new engineering)
Book Neo London / AntiGravity as a live act. `/performances` page +
`/commission?type=performance` now live. Turn the example katas into a
rehearsed repertoire; demo reel next.

## Phase 2 — Sell the object (genome + laser bundle)
Extend the existing genome->print pipeline (genome-print.ts,
Slant3D/Treatstock fulfillment) so a customer's evolved sculpture genome
also generates a matching laser show. Needs a genome->choreography
mapping that doesn't exist yet.

## Phase 3 — Sell the software (HoloLaser product)
Package hololaser_os itself as something other flow-arts people buy —
the WebGPU preview (see holo-core HoloVR laser simulation) becomes the
selling surface. Biggest lift, biggest differentiator (nothing else in
laser software is poi-first).
