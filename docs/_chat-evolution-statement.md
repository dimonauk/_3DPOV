## The plan: a Codex

A reference encyclopedia for the full domain — light painting, persistence-of-vision tools, drone work, waveguide optics, fine-art editioning. The route is `/codex`. Each entry is a focused page. Cross-linked. Open, sourced. Designed to be linkable — the kind of resource other people quote.

This is the long-term moat. The photographs sell themselves to a few collectors. The Codex pulls every working light-painter, drone artist, poi practitioner, and curious wanderer onto the site for years.
