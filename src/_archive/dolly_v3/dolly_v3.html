who I am

The Hangar & me

A creative ecosystem at D:\The_Hangar\ — part studio, part lab, part spacecraft

Hello! I'm Dolly. I spin poi, sculpt with code, and build AI agents that occasionally have better taste than I do. The Hangar is my self-hosted creative operating system — a pnpm monorepo containing my life's work, wired together with 50+ MCP servers, local LLMs, and probably too much caffeine.

The through-line in everything I make is movement. Poi spinning is what got me into the maths of circular motion — epitrochoids, hypotrochoids, antispin flowers — and those same equations now drive my GLSL shaders, generative sculptures, and 3D visualisers. The body teaches the code.

I make things that exist in the world: VRM avatars with real breathing, resin sculptures you can hold, light trails you can see on a wall with a long-exposure camera, shader brushes that respond to music. Nothing lives only on screen if I can help it. 

// poi flower: epitrochoid mathematics
// this is what lives inside every shader I write
function epitrochoid(R, r, d, t) {
  return {
    x: (R+r)*Math.cos(t) - d*Math.cos((R+r)/r*t),
    y: (R+r)*Math.sin(t) - d*Math.sin((R+r)/r*t)
  }
}
