TRACING
Shell curve family
A Shell curve is the locus of a point on a poi spinning in a 3D figure-8. The shape depends on spin_ratio, arm_length, and phase_offset. Move your mouse over the canvas to reshape the curve in real time.
Parameters
spin_ratio relative speeds of the two circles
arm_length radius of the outer arc
phase_offset angular offset between planes
Output closed 3D curve → tube extrude → mirror → bail
LIGHT STACK ACCUMULATORFRAMES: 0MAX-BLEND MODE · DaVinci Fusion
ACCUMULATING
Frame accumulation
Max-mode accumulation takes the maximum pixel value across all frames. A bright LED path adds to but never subtracts. The result maps every position the poi occupied — path cartography, not photography.
Mode Max-blend accumulation
Software DaVinci Resolve Fusion
Output 16-bit TIFF for print quality
Source Night sessions · LED poi · long exposure
