# `reaction-diffusion-shell.tsx` — purpose twin

## Role

Live Gray-Scott reaction-diffusion visualiser for the
`/visualiser/reaction-diffusion` route. A 128×128 grid is
simulated per frame (two PDE steps + Canvas2D paint) with F + k
sliders, five named presets, and run/pause/reset controls.

The companion to `lib/algorithms/reaction-diffusion.ts` — that
file is the *atelier port* (outputs a heightmap mesh of the final
field); this page is the *live process* (watch the regimes
emerge).

## Public surface

- Default export `ReactionDiffusionShell` — no props.

## Internal

- `N = 128` — grid resolution.
- `DU, DV, DT` — diffusion constants and timestep.
- `PRESETS` — Mitchell's classic gray-scott parameter table.
- `seed(u, v)` — initial conditions: full `u`, central disc of `v`.
- `step(u, v, un, vn, F, k)` — Forward Euler with toroidal
  boundary and 5-point Laplacian. Reads from `u, v`, writes to
  `un, vn`. Caller swaps buffers.
- `paint(ctx, v)` — pink-on-midnight palette mapped from the
  `v` field via per-pixel ImageData.
- Buffer pair stored in a `ref`, not state — mutation per frame
  must not trigger React re-renders.
- Generation counter triggers a re-seed on preset / reset clicks.

## Depends on

- `react` — `useState`, `useEffect`, `useRef`, `useMemo`.
- Browser globals: `HTMLCanvasElement`, `CanvasRenderingContext2D`,
  `requestAnimationFrame`, `ImageData`.

## Does not

- **Does not import the algorithm port.** The atelier port
  (`lib/algorithms/reaction-diffusion.ts`) outputs a heightmap
  mesh; this visualiser runs the per-frame chemistry as 2D pixels.
  Different consumers of the same equation.
- **Does not write to any slice.** Self-contained.
- **Does not use Three.js / R3F.** Plain Canvas2D — appropriate
  for a 2D scalar field. Lighter-weight than dragging in a
  whole 3D renderer.
- **Does not handle resolution scaling.** Fixed 128×128. The
  CSS `image-rendering: pixelated` upscales without blur.

## Bordering files

- `lib/algorithms/reaction-diffusion.ts` — sibling port that

- `app/visualiser/reaction-diffusion/page.tsx` — server shell.
