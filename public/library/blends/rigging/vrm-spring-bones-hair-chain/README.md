# VRM Spring Bones — Bone Collections + Hair-Chain Physics

**Blender 5.1 · Rigging · CC0**

Builds a five-bone character armature (Root → Spine → Head → Hair_1…Hair_4)
with two bone collections — `Humanoid` and `SpringBone_Hair` — and exports a
skinned GLB.  Spring bone parameters (stiffness, drag, hit radius) are stored
as custom properties, ready to be mapped to the VRM Addon's `VRMC_springBone`
panel for a full `.vrm` export.

## Key API facts

| API | Blender version | Notes |
|-----|----------------|-------|
| `arm.collections.new(name)` | 4.0+ | Replaces 32-bit bone layer flags |
| `coll.assign(bone)` | 4.0+ | Works with Bone, EditBone, PoseBone |
| `coll.color_set = 'THEME08'` | 4.0+ | Per-collection viewport colour |
| `use_connect = False` on spring bones | all | Required for free-pivot spring joints |
| `export_skins=True` | all | Embeds JOINTS_0 / WEIGHTS_0 in GLB |
| Draco disabled | all | Undefined interaction with skinned meshes in spec |

## Generated files

| File | Description |
|------|-------------|
| `vrm_spring_bones.blend` | Live armature with bone collections + custom props |
| `vrm_spring_bones.glb` | Skinned GLB; no Draco; no VRMC_springBone (standard export) |
| `viewport.mp4` | EEVEE render of hair-chain pendulum sway (generated by record.py) |
| `screen.mp4` | OBS screen capture — see SCREEN-RECORDING-NOTES.md |

## Run order

```bash
blender --background --python blueprint.py
blender --background --python record.py
```
