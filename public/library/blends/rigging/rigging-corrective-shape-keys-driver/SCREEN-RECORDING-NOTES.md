## Blender Workspace Layout

Open the `.blend` generated by `blueprint.py`, then arrange:

- **Left 60%**: 3D Viewport — Solid shading, `Z` → Solid, Camera not locked
- **Top-right 20%**: Properties panel → Object Data → Shape Keys (show corrective key value updating)
- **Bottom-right 20%**: Spreadsheet editor or Graph Editor showing the driver curve

Switch to **Pose Mode** so the viewer can see bone handle manipulations.

## Shot List (target: 4-6 minutes)

### 1. Intro shot (0:00 – 0:30)
- Arm mesh straight, bones visible (Armature overlay on)
- Slowly pan camera around the elbow from the front

### 2. Demonstrate the problem (0:30 – 1:30)
- In Pose Mode, manually rotate the forearm bone to −90° on X
- Show the elbow **pinching inward** — pause for 3 seconds
- Reset to 0°

### 3. Shape Keys panel tour (1:30 – 2:00)
- Click Object Data Properties → Shape Keys
- Show Basis key, then add `elbow_corrective` key
- Scrub the value slider from 0 → 1 with the arm at rest; the posterior elbow
  should push outward

### 4. Add the driver (2:00 – 3:30)
- Right-click the `elbow_corrective` value field → **Add Driver**
- In the Driver panel (Graph Editor → Drivers sidebar):
  - Type: `Scripted Expression`
  - Variable type: `Transform`
  - ID: select the armature object
  - Bone: `forearm`
  - Type: `X Rotation`
  - Space: `Local Space`
  - Expression: `max(0.0, min(1.0, -var / 1.5708))`

### 5. Final result (3:30 – 5:00)
- Pose Mode, rotate forearm 0° → −90° slowly
- Viewport shows corrective key value animating in Properties panel
- Cut to a side-by-side: without corrective (value=0 locked) vs with corrective (driver live)
- Let the arm swing back and forth 2× for the closing shot
