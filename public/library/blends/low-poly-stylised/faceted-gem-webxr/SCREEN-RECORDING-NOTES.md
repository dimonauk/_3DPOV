# Screen Recording Notes — Faceted Gem (Blender 5.1)

These notes are for Dimona recording `screen.mp4` from a live Blender session.
The viewport recording (`viewport.mp4`) is generated by `record.py` automatically.

---

## Setup

| Setting | Value |
|---------|-------|
| Software | OBS Studio or Windows Game Bar (Win+G) |
| Source | Window Capture → Blender |
| Resolution | 1920 × 1080 |
| Frame rate | 30 fps |
| Audio | Off (or muted — no commentary needed for the raw capture) |
| Output | `public/library/videos/low-poly-stylised/faceted-gem-webxr/screen.mp4` |

---

## What to record (runtime: ~12–15 min)

### Part 1 — open the script (1 min)
1. Open Blender 5.1. New General file.
2. Split the 3D Viewport: drag a corner to create a second panel → set it to **Text Editor**.
3. In the Text Editor, click **New** → rename to `blueprint.py`.
4. Open `public/library/blends/low-poly-stylised/faceted-gem-webxr/blueprint.py` in a text editor on your OS, copy the full contents, paste into Blender's Text Editor.

### Part 2 — run the blueprint (30 s)
5. Press **Alt+P** (Run Script) with the cursor in the Text Editor.
6. The gem appears in the 3D Viewport. Pan the camera with **middle-mouse** to look at it from the side, then from below.

### Part 3 — inspect geometry (3 min)
7. Select the gem. Press **Tab** to enter Edit Mode.
8. Press **Alt+Z** (X-ray), select a crown quad face — show in the info bar that it has exactly 4 verts.
9. Select a pavilion triangle.
10. Press **N** to open the sidebar → **Item** tab → show the face normal vector.
11. Tab back to Object Mode.

### Part 4 — inspect the material (3 min)
12. Open **Shader Editor** (top-left corner menu → Shader Editor).
13. Show the node tree: Principled BSDF → MixShader alongside the Layer Weight and ColorRamp.
14. Click the ColorRamp — zoom in so the viewer can see the CONSTANT interpolation and the 3 colour stops clearly.
15. Drag one stop position while watching the gem change in the viewport — shows the cel banding at work.

### Part 5 — flat vs smooth shade comparison (2 min)
16. With the gem selected: **Right-click** → **Shade Smooth**. Show the gem losing its faceted look.
17. Right-click → **Shade Flat**. Facets snap back.

### Part 6 — export to GLB (2 min)
18. **File → Export → glTF 2.0 (.glb/.gltf)**.
19. In the export dialog: tick **Mesh Compression (Draco)**, set level to **6**; tick **Images: WebP**.
20. Set the filepath to `public/library/glbs/low-poly-stylised/gem_cobalt.glb`.
21. Click **Export glTF 2.0**.

### Part 7 — quick turntable (1 min)
22. Switch to the default **Layout** workspace.
23. Set timeline to frame 1. Press **Spacebar** to play. Show the gem rotating (if `record.py` was run, the animation is already keyed).

---

## Editing notes

- Trim silence / dead time.
- No music needed; raw viewport audio (or muted) is fine.
- Export at 1080p H.264 CRF ~20.
- Filename: `screen.mp4` in the same folder as `viewport.mp4`.
