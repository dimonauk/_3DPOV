# GP3 Frame-by-Frame Cel Animation — Bouncing Ball

**Blender 5.1 · Grease Pencil 3 · CC0**

A programmatic implementation of the classic bouncing ball test using
Grease Pencil 3's frame/drawing data model. Demonstrates squash & stretch,
arc of motion, timing via frame spacing, onion skinning, and PNG sequence
render with transparent background.

## What this teaches

- How GP3 `layer.frames.new(N)` places a drawing at timeline frame N and
  HOLDS it until the next drawn frame — distinct from NLA/Object keyframes
- Squash & stretch encoded as different ellipse point arrays per keyframe
- Timing: why frames 1→7 (fast fall) use fewer in-betweens than 14→24
  (slow rise) to match physics-like acceleration
- Proximity shadow as a separate layer scaled inversely with ball height
- Onion skinning API: `gp.use_onion_skinning`, `onion_mode='ABSOLUTE'`,
  `onion_before_range`, `onion_color_before/after`
- OpenGL viewport render via `bpy.ops.render.opengl(animation=True)` to
  capture the onion skin ghost overlay in the output frames

## Files

| File | Purpose |
|---|---|
| `blueprint.py` | Build + render the 24-frame bounce animation |
| `record.py` | Viewport OpenGL render capturing onion skins |
| `SCREEN-RECORDING-NOTES.md` | OBS instructions for screen.mp4 |
| `bounce_ball.blend` | Generated by blueprint.py |
| `output/bounce_*.png` | 24-frame PNG sequence (RGBA, transparent BG) |

## Run order

```bash
# Inside Blender 5.1 Script Editor or via blender --background --python:
python blueprint.py   # creates bounce_ball.blend + PNG sequence
python record.py      # OpenGL viewport render + onion-skin capture
```

## Keyframe timing

| Frame | State | Shape |
|---|---|---|
| 1 | Apex (top) | Circle r=0.28 |
| 7 | Mid-fall | Circle r=0.28 |
| 12 | Impact | Squash rx=0.50 ry=0.13 |
| 14 | Rebound | Stretch rx=0.18 ry=0.44 |
| 24 | Second apex | Circle r=0.25 |
