# Screen Recording Notes — GP3 Frame-by-Frame Cel Animation

OBS / Windows Game Bar instructions for capturing `screen.mp4`.

## Setup

| Setting | Value |
|---|---|
| Window source | Blender 5.1 (windowed, not borderless) |
| Capture resolution | 1920 × 1080 |
| Output resolution | 1920 × 1080 |
| Frame rate | 30 fps |
| Audio | Off (no mic / no desktop audio) |
| Output format | MKV → remux to MP4 after recording |

## OBS Scene Layout

One source: Window Capture → Blender. Scale to fill the 1920×1080 canvas.
No additional overlays, webcam, or annotations during the base recording.

## Recording Flow

### Part 1 — Workspace setup

1. Open Blender 5.1. Switch to the **2D Animation** workspace (or manually
   arrange: GP3 object in 3D Viewport left, Dopesheet right, Timeline bottom).
2. With `bounce_ball.blend` loaded, scrub to frame 1 in the Timeline.
3. In the 3D Viewport header → Overlays → enable **Onion Skins**.
   Show the onion skin being toggled on — this is a key visual moment.

### Part 2 — Dopesheet walk-through

4. Open the Dopesheet (Animation mode → filter to show the active GP3 layers).
   The three layers (BG, Ball, Shadow) and their keyframe diamonds appear.
5. Click each keyframe diamond in the Ball layer in sequence: 1, 7, 12, 14, 24.
   Pause ~1 second on each so the viewer can see the squash/stretch shape and
   the blue/red ghost frames from neighbouring keyframes.
6. Scrub slowly between frame 12 (squash) and frame 14 (stretch) to show the
   snap-transition — this demonstrates that the hold between keyframes is
   abrupt by design, not interpolated.

### Part 3 — Blueprint.py run (optional)

7. Open the Scripting workspace. Load `blueprint.py`.
   Click **Run Script** and let it execute to completion.
   Show the 24-frame PNG sequence appearing in the output/ folder via the
   File Browser.

### Part 4 — Render preview

8. Back in 3D Viewport: press Space to play the animation (frames 1–24).
   Slow the playback if needed via Timeline → Playback Speed → ½ or ¼.
9. Optionally open Image Editor → Render Result to flip through the rendered
   PNG frames showing the amber ball in mid-bounce.

### Part 5 — Wrap

10. Return to frame 12 (the squash impact). Leave the onion skins visible.
    This is the thumbnail frame — amber squashed ball on transparent background,
    blue ghost of the mid-fall above it, red ghost of the rebound below it.

Target: 4–8 minutes at normal speed. The Dopesheet walk-through is the core
segment; edit it down to under 3 minutes if trimming for social.
