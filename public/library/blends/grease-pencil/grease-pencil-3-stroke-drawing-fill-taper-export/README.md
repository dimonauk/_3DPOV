## What this entry covers

Grease Pencil 3 (GP3), shipped as the default in Blender 4.3 and refined through 5.1, is a complete data-model rewrite of the original GP system. This entry focuses on the **stroke-authoring** side of GP3 — creating ink strokes programmatically, configuring GP3 materials (stroke colour + fill colour), and building a modifier stack that gives strokes a tapered ink-brush feel.

Separate from this entry: the [GP3 Line Art modifier tutorial](/tutorials/blender-tutorial-grease-pencil-3-line-art-toon-outline) covers analysing mesh edges to auto-generate ink outlines. *This* entry is about drawing original 2D geometry as GP3 strokes.

## GP3 data model quick reference

```
bpy.types.Object  (type='GREASE_PENCIL_V3')
└── obj.data  →  bpy.types.GreasePencil
    ├── .layers[]  →  GreasePencilLayer
    │   └── .frames[]  →  GreasePencilFrame
    │       └── .drawing  →  GreasePencilDrawing
    │           └── .strokes[]  →  GreasePencilStroke
    │               └── .points[]  →  GreasePencilPoint (.position, .radius, .opacity)
    └── .materials[]  →  Material  (with .grease_pencil GP data)
        ├── .grease_pencil.color         (stroke RGBA)
        ├── .grease_pencil.fill_color    (fill RGBA)
        ├── .grease_pencil.show_stroke   (bool)
        └── .grease_pencil.show_fill     (bool)
```
