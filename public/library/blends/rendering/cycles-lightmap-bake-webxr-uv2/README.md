# Cycles Lightmap Baking for WebXR — UV2 Channel, Combined Bake, OIDN, GLB Export

**Blender 5.1 · Cycles · CC0**

Pre-bake scene lighting (direct + indirect + shadows) into per-object UV2 textures
so the exported GLB runs at flat texture-sample cost in WebXR — no runtime ray
tracing required.

## What this builds

A small architectural scene — floor, two walls, a pillar, an accent block —
lit by a warm area key and a cool point fill.  Each mesh carries:

- **UV0** `"UVMap"` — standard material UV (TEXCOORD_0); islands may overlap
- **UV1** `"UVLightmap"` — lightmap UV (TEXCOORD_1); islands uniquely placed,
  no overlaps permitted

Cycles bakes a `COMBINED` pass (direct + indirect, all bounces, OIDN denoised)
into a 512×512 float image per mesh.  The images are packed into
`lightmap_room.blend` and embedded in `lightmap_room.glb`.

## Usage

```bash
# 1. Build the scene and bake lightmaps
blender --background --python blueprint.py

# 2. Record the orbit video (opens the generated blend)
blender --background lightmap_room.blend --python record.py
```

## Three.js lightMap setup

```js
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js';

const loader = new GLTFLoader();
loader.load('lightmap_room.glb', (gltf) => {
  gltf.scene.traverse((child) => {
    if (!child.isMesh) return;
    // TEXCOORD_1 lands in geometry.attributes.uv1 (Three.js r148+: uv1)
    const lmTex = child.material.map;          // already embedded in GLB
    child.material.lightMap = lmTex;           // assign to lightMap slot
    child.material.lightMapIntensity = 1.0;
    child.material.needsUpdate = true;
  });
});
```

> Three.js r148+ renames `uv2` → `uv1` for the second UV set.
> Check your Three.js version: if lightMap appears black, try
> `geometry.setAttribute('uv1', geometry.getAttribute('uv2'))` for older builds.

## Bake types at a glance

| Type | What it captures | Use when |
|------|----------------|----------|
| `COMBINED` | Direct + indirect + shadow + AO | Full GI snapshot — best for WebXR |
| `DIFFUSE` | Only diffuse colour response | Colour bleed analysis |
| `AO` | Ambient occlusion only | Multiplied over albedo in shader |
| `SHADOW` | Cast shadows only | Shadow maps without colour |

## Shared atlas variant

For fewer draw calls, pack all faces into one image:

```python
# 1. Select all MESHES, enter Edit Mode (multi-object)
bpy.ops.object.select_all(action='SELECT')
bpy.ops.object.mode_set(mode='EDIT')

# 2. Lightmap Pack across selected objects into a shared UV1 space
bpy.ops.uv.lightmap_pack(
    PACK_IN_ONE=True,
    NEW_UVLAYER=False,   # write into active UV layer (must be UV1)
    NEW_MESH=False,
    SHARE_TEX=True,
)
bpy.ops.object.mode_set(mode='OBJECT')
```

Then bake all objects sequentially into the SAME image.
