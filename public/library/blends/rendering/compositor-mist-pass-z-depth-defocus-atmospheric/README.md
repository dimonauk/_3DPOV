## What this teaches

Two depth-based compositor effects used together:

1. **Z-Depth Defocus** — the Compositor's Defocus node reads the raw depth
   buffer (Z pass) and applies lens-accurate bokeh without touching the camera's
   render-time DOF. The F-Stop matches the camera, so the blurred result is
   physically consistent with what the camera would produce at that aperture.

2. **Atmospheric Mist** — the Mist pass is a pre-normalised depth buffer where
   0 = at the camera, 1 = beyond the mist depth. A Mix node lerps the blurred
   beauty pass towards a fog colour using the Mist pass as the factor. Near
   objects stay crisp and unfogged; far objects dissolve into the atmospheric
   haze.

Using both in sequence: Defocus blurs distant geometry → Mist fades it into
the sky colour → result looks like real-world haze.

## Key parameters (top of blueprint.py)

| Constant | Default | Effect |
|----------|---------|--------|
| `F_STOP` | 2.8 | Aperture; halve to double the blur radius |
| `FOCUS_DIST` | 5.0 | World units to focus plane |
| `MIST_START` | 1.0 | World units before mist begins |
| `MIST_DEPTH` | 8.0 | Range over which mist ramps 0 → 1 |
| `MIST_FALLOFF` | QUADRATIC | Curve shape of the mist ramp |
| `FOG_COLOUR` | cool blue-grey | RGBA to blend towards at mist=1 |
