# HookModifier — Vertex-Group Bind to Empty (Headless-Safe)

**Blender 5.1 · CC0 · Holoflow Studio**

`bpy.types.HookModifier` binds a named vertex group to an Empty object so the
Empty's world transform drives vertex displacement.  It is the lightest-weight
deformation tool in Blender's stack — no armature, no shape keys, no GN tree.

The critical headless gotcha: in the UI the operator `object.hook_add_selob`
writes `matrix_inverse` automatically.  In a script you must set it yourself:

```python
bpy.context.view_layer.update()           # flush matrix_world on new objects
mod.matrix_inverse = empty.matrix_world.inverted()
```

Skip that line and frame 0 shows phantom deformation even when the Empty is at
its rest position, because Blender interprets the identity matrix as "the Empty
was at world origin at bind time."

## What this blueprint builds

A faceted pentagon drop-earring (12 verts, gold PBR) with two Hook modifiers:

| Modifier | Vertex group | Empty pivot | Falloff radius | Swing |
|---|---|---|---|---|
| `HK_hk_upper` | verts 1–5 (upper ring) | Z = −0.30 | 0.22 m | ±0.08 m |
| `HK_hk_lower` | vert 11 (spike tip) | Z = −1.10 | 0.14 m | ±0.22 m |

Both hooks animate a SINE / EASE_IN_OUT pendulum over 72 frames, with the lower
pivot phase-shifted so the spike trails the upper ring — classic earring physics.

The GLB export uses `export_apply=False` + `export_animations=True` so the
modifier is baked per-frame by the depsgraph during export — no manual
"Apply All" step needed.

## Key API

```python
mod = ob.modifiers.new("HK_upper", "HOOK")   # bpy.types.HookModifier
mod.object         = empty
mod.vertex_group   = "hk_upper"
mod.falloff_type   = "SPHERE"          # SPHERE / LINEAR / CONSTANT / SMOOTH
mod.falloff_radius = 0.22
mod.use_falloff_uniform = True         # corrects for non-uniform ob scale
mod.force          = 0.90              # weighting scalar (NOT .strength)

# Headless bind — must set both:
bpy.context.view_layer.update()
mod.center         = ob.matrix_world.inverted() @ empty.matrix_world.translation
mod.matrix_inverse = empty.matrix_world.inverted()
```
