# Hopf Fibration — S³ → S² Circle Bundle

**Heinz Hopf, 1931** · Blender 5.1 · CC0 · Topic: Topology / Quaternions

## What is this?

The Hopf fibration is a smooth surjection π : S³ → S² where every preimage
π⁻¹(p) is a circle.  The 3-sphere S³ is fibred by circles, and any two
distinct circles are linked exactly once — the linking number is 1 for every
pair.  Hopf published it in 1931 as the first non-trivial example of a
topological space with a fibre bundle structure; it is also the generator
of the third homotopy group π₃(S²) ≅ ℤ.

In Blender terms, the Hopf fibration is the geometry underneath every
quaternion rotation: the unit quaternions form S³, and the map q ↦ q·i·q̄
(conjugation by unit imaginary i) sends each quaternion to a point on S².
Every SLERP path traces a Hopf fibre.

## Running

1. Open Blender 5.1 with a new General file.
2. Open the Scripting workspace.
3. Load and run `blueprint.py` — it builds `hf_hopf_poi.blend` + `hf_hopf_poi.glb`.
4. (Optional) Run `record.py` in background to render `viewport.mp4`.

## Key parameters

| Constant | Value | Effect |

| `N_FIBERS` | 48 | Base points on S² (Fibonacci lattice) |
| `N_FIBER_STEPS` | 80 | Vertices along each fibre circle |

## Shape keys

| Key | Description |
|-----|-------------|
| Basis | Fibonacci-sphere distribution, all 48 fibres |
| SK_Clifford | All base points on S² equator → Clifford torus of interlocked circles |
| SK_SouthHeavy | Base points clustered in southern hemisphere → tight rings near origin |
| SK_NorthHeavy | Base points clustered in northern hemisphere → large rings near ∞ |
| SK_Taut | Same as Basis, tube radius halved → thin wires emphasise linking |

## Mathematics

```
S³ ⊂ ℂ²:   |z₁|² + |z₂|² = 1

Hopf map:   π(z₁,z₂) = (2 Re(z₁z̄₂),  2 Im(z₁z̄₂),  |z₁|²−|z₂|²)  ∈ S²

Fibre over p=(sin θ cos φ, sin θ sin φ, cos θ):
    z₁(α) = √((1+cos θ)/2) · e^{iα}
    z₂(α) = √((1−cos θ)/2) · e^{i(φ+α)}       α ∈ [0,2π)

Stereographic projection from (1,0,0,0) ∈ S³:
    (w,x,y,z)  ↦  (x/(1−w), y/(1−w), z/(1−w))  ∈ ℝ³

Linking number of any two fibres:  L(γ₁, γ₂) = 1
π₃(S²) ≅ ℤ generated by the Hopf invariant of π
Clifford torus:  |z₁| = |z₂| = 1/√2,  a flat minimal torus in S³
```
