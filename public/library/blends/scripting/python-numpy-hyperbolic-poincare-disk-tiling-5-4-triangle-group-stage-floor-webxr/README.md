# Hyperbolic {5,4} Tiling — Poincaré Disk Stage Floor

**Category**: scripting · **Blender**: 5.1 · **Licence**: CC0

## What this is

A stage floor for WebXR performances built from the {5,4} hyperbolic tiling —
regular pentagons with four meeting at every vertex — computed inside the
Poincaré disk model of the hyperbolic plane.

At the boundary of the disk the tiles grow infinitesimally small in the
Euclidean sense but are all geometrically identical: hyperbolic geometry is
"scale-invariant at large scales" the same way Euclidean geometry is at
small scales.  The resulting pattern is the Poincaré-disk version of M.C.
Escher's *Circle Limit* woodcuts (Escher used {6,4}, hexagons with four at
each corner).

## Mathematical background

The {5,4} tiling satisfies (p−2)(q−2) = 6 > 4, confirming hyperbolic geometry.
Interior vertex angle = 2π/4 = π/2 (right angles at every corner).
Circumradius ρ ≈ 0.307 in the Poincaré disk; generated by BFS-applying Möbius
reflections across each pentagon side.
