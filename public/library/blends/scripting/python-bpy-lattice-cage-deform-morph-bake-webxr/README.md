# Python bpy.types.Lattice — Cage Deformer: Control Point Scripting & GLB Bake for WebXR

Blender 5.1 · Holoflow Studio scripting library · CC0

## What this does

`blueprint.py` builds a 32×32 subdivided column mesh, deforms it through a
procedurally controlled 4×4×3 Lattice cage (radial sine wave + inward pinch
on the top layer), applies (bakes) the LATTICE modifier, and exports the
result as a Draco-compressed GLB ready for WebXR delivery.

## Why a Lattice rather than shape keys or GN displacement?

| Approach | Topology change? | Reversible? | Multiple targets? |
|---|---|---|---|
| Shape key | No | Yes (slider) | Yes (N keys) |
| GN displacement | No | Yes (modifier) | Via fields |
| Lattice | No | Yes (before apply) | Yes (swap mod.object) |

Lattices are unique in that swapping `mod.object` to a different lattice
object replaces the entire deformation without touching the mesh.  This makes
them efficient for generating shape variants of a shared base mesh — only the
lattice data differs, not the mesh topology.

## Control point index formula

```python
idx = u + v * U + w * U * V
```

U = `lattice.points_u`, V = `lattice.points_v`, W = `lattice.points_w`.  All
axes are 0-based.  Forget the formula once and every manual point lookup
produces incorrect vertex positions with no runtime error.

## Key API surface

| Attribute | Notes |
|---|---|
| `lat.points_u/v/w` | Set before first access to `lat.points` — resizing afterwards resets co_deform |
| `pt.co` | Rest-grid position — read-only after creation |
| `pt.co_deform` | Deformed position — writeable |
| `lat.interpolation_type_u/v/w` | `'KEY_LINEAR'` / `'CARDINAL'` / `'BSPLINE'` |
| `mod.object` | Must be the lattice **Object**, not the Lattice data block |
| `mod.vertex_group` | Optional: limit deformation to named vertex group on the mesh |

## Output artefacts

| File | Description |
|---|---|
| `blueprint.py` | Full build + export script |
| `record.py` | Orbiting viewport render → `viewport.mp4` |
| `SCREEN-RECORDING-NOTES.md` | OBS capture instructions → `screen.mp4` |
| `holoflow_lattice_baked.glb` | Draco-compressed baked mesh (generated by blueprint.py) |

## Running

Open `blueprint.py` in the Blender 5.1 Scripting workspace and press ▶.
The script clears the scene, builds the mesh and cage, applies the modifier,
and exports `holoflow_lattice_baked.glb` relative to the .blend file location.
