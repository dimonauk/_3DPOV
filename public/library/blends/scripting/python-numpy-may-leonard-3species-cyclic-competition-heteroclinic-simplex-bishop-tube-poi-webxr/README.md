# May–Leonard 3-Species Cyclic Competition
## Heteroclinic Cycles on a Population Simplex · Blender 5.1 · CC0

**System**: May & Leonard (1975) 3-species competition with cyclic (rock–paper–scissors) dominance.  
**Geometry**: Bishop parallel-transport tube tracing the trajectory in (x₁,x₂,x₃) population space.  
**Output**: Poi head GLB for WebXR, four shape keys spanning heteroclinic, coexistence, and reversed-dominance dynamics.

---

## Equations

```
ẋ₁ = x₁(1 − x₁ − α·x₂ − β·x₃)
ẋ₂ = x₂(1 − β·x₁ − x₂ − α·x₃)    cyclic shift of the competition matrix
ẋ₃ = x₃(1 − α·x₁ − β·x₂ − x₃)

Canonical (May–Leonard 1975): α = 0.50, β = 1.50  (α+β = 2)
Interior fixed point: x* = (1/(1+α+β), 1/(1+α+β), 1/(1+α+β)) = (1/3, 1/3, 1/3)
```

The cyclic structure (x₁ beats x₂ beats x₃ beats x₁, with asymmetric rates α≠β)
breaks the symmetry of standard Lotka–Volterra and creates a *heteroclinic orbit*:
the trajectory is drawn from the interior equilibrium toward a triangular cycle on
the boundary of the simplex, connecting the three single-species vertices
(1,0,0) → (0,1,0) → (0,0,1) → (1,0,0).

## Phase-space divergence

```
div F = 3 − (2 + α + β)·N    where N = x₁ + x₂ + x₃
```

For canonical α + β = 2: `div = 3 − 4N`.  
At any single-species vertex (N ≈ 1): `div ≈ −1` — contracting.  
At the interior fixed point (N = 1): `div = −1`.  
This is NOT constant (unlike Lorenz/Chen), so the Liouville sum-of-Lyapunov check
gives only a time-averaged constraint.

## Colour attribute

`MayLen_X1` (FLOAT_COLOR, POINT domain) — normalised species-1 population x₁.  
Cobalt: x₁ small (species 1 rare). Amber: x₁ large (species 1 dominant).  
The gradient cycles cobalt → amber → cobalt → amber as x₁ oscillates through each heteroclinic pass.
