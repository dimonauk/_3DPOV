# Kummer Quartic — 16-Node Maximum-Singularity Surface & Poi Head

**Topic:** scripting · **Blender:** 5.1 · **Licence:** CC0

A degree-4 algebraic surface holding the maximum possible number of ordinary
double points (nodes) for a quartic: **16**.  The bound was proved by Ernst
Eduard Kummer in 1864 and stands as a landmark result in singularity theory.

## Key equation

```
f(x,y,z) = (x²+y²+z²−μ²)² − λ·[(1−z)²−2x²]·[(1+z)²−2y²] = 0

μ = 1.2    λ = (3μ²−1)/3 ≈ 1.107
```

For μ > 1: 12 of the 16 nodes are in ℝ³; the other 4 are at projective infinity.
