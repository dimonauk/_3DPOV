# SDF CSG: Quilez Primitives, Smooth Boolean Operations & Poi Head GLB

**Blender 5.1 · Python 3.11 · CC0**

A Signed Distance Field (SDF) assigns to every point in space its signed
nearest-surface distance: negative inside, positive outside, zero on the
surface.  Because the sign encodes inside/outside, Boolean CSG reduces to
plain arithmetic — `union = min(a, b)`, `difference = max(a, −b)` — and
complex compound shapes collapse to one function evaluation per grid cell.

Inigo Quilez's smooth minimum replaces the discontinuous `min` with a
C¹-continuous blend over radius `k`, letting two forms melt into each other
without a sharp seam.  This is the workhorse behind most organic procedural
forms in contemporary real-time graphics.

## Algorithm at a Glance

```
sphere(body) ──smin──┐
torus(ring)  ──smin──┤ shell
                     ├──sdiff── shape ──smin── FINAL
dome(cavity) ──────────sdiff──┘             │
stem(capsule) ─────────────────────smin─────┘
```

- Grid: 72³ lattice over ±1.05 m → ~373 k cells
- Isosurface extraction: Surface Nets (Gibson 1998)
- Export: Draco-6, WebP textures, +Y-up, `snake_case` root name
