# bpy + bmesh — Procedural Dodecahedron (Blender 5.1)

A regular dodecahedron — 12 regular pentagonal faces, 20 vertices, 30 edges —
constructed entirely from golden-ratio coordinates via Blender's `bmesh`
direct-data API.  No primitive operators, no Geometry Nodes: just maths and
the mesh data API.

## Files

| File | Purpose |
|---|---|
| `blueprint.py` | Build scene, material, animation, export `.blend` + `.glb` |
| `record.py` | EEVEE render of the 120-frame spin to `viewport.mp4` |
| `SCREEN-RECORDING-NOTES.md` | OBS instructions for the `screen.mp4` walkthrough |
| `dodecahedron.blend` | Generated by `blueprint.py` |
| `dodecahedron.glb` | Draco-compressed GLB ready for WebXR |

## Quick start

```bash
# headless (CI / batch)
blender --background --python blueprint.py

# interactive
# Open Blender → Scripting workspace → Open blueprint.py → Run Script
```

## What it demonstrates

- `bmesh.new()` for context-independent mesh creation
- Golden-ratio vertex coordinates (two algebraic orbits under A₅)
- `bm.faces.new()` for pentagonal face construction
- `mesh.polygons[i].use_smooth = False` for flat (faceted) shading
- `bpy.data.materials.new()` + node-tree API for Principled BSDF setup
- `bpy.data.objects.new()` to link objects without operator context
- `bpy.ops.export_scene.gltf()` called from script context with Draco + WebP

## Mathematical background

The 20 vertices come from three orbits of the rotation group A₅:

| Orbit | Coordinates | Count |
|---|---|---|
| Cube corners | (±1, ±1, ±1) | 8 |
| φ-rectangles XZ | (0, ±1/φ, ±φ) | 4 |
| φ-rectangles XY | (±1/φ, ±φ, 0) | 4 |
| φ-rectangles YZ | (±φ, 0, ±1/φ) | 4 |

All 20 vertices lie on a sphere of radius √3 (circumradius of the cube).
`blueprint.py` normalises to `SCALE = 1.0` Blender units.

Euler characteristic: V − E + F = 20 − 30 + 12 = **2** ✓
