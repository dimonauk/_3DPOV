## What this makes

A 256 × 256 height-field quad mesh. Each vertex is coloured by which root of
z^5 − 1 the Newton iterator converges to from that starting point, and raised
by an amount proportional to how slowly it converged. The slowest pixels — the
fractal basin boundary — form sharp ridges. The result is a stage floor with
five-fold symmetry whose silhouette traces the Julia set of the Newton map.

Shape keys let you morph between z^3 − 1 (three basins, three-fold symmetry),
z^5 − 1 (basis), and z^7 − 1 (seven basins) at runtime in WebXR.

## Mathematics

Newton's method on p(z) = z^n − 1 converges to one of the n-th roots of unity
e^(2πi·k/n). The simplified iteration avoids division-by-cancellation:

```
N(z) = ((n−1)·z^n + 1) / (n·z^(n−1))
```

Near any basin boundary the iteration behaves chaotically — the boundary is
the Julia set of N, a fractal set with Hausdorff dimension > 1. Iteration
count is log-compressed and used as vertex height, making boundary ridges
prominent without swamping the flat basin interiors.
