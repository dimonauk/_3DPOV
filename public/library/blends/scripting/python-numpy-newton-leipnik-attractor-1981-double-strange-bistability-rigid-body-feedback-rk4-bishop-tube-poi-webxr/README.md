# Newton–Leipnik Attractor — Double Coexisting Strange Attractors (1981)

**Topic:** `scripting` | **Blender:** 5.1 | **Licence:** CC0

## What this is

Newton & Leipnik (1981) were studying feedback control of a rigid body when
they discovered that their system possessed two *simultaneously existing*
strange attractors for the same parameter values.  This is genuinely rare:
most chaotic systems have one strange attractor per parameter setting.  Here,
two coexisting strange attractors occupy distinct, interleaved basins of
attraction in the same phase space.

The blueprint builds both attractors as Bishop parallel-transport tubes joined
in a single mesh object.  The cobalt-to-amber tube is the upper attractor
(initial condition near IC_UPPER); the white-to-crimson tube is the lower
attractor (IC_LOWER).

## Equations

```
ẋ = −a·x + y + 10·y·z
ẏ = −x − 0.4·y + 5·x·z
ż =  b·z − 5·x·y

Canonical: a = 0.4, b = 0.175
∇·F = −0.625 (constant)
```
