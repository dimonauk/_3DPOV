# Python — depsgraph.object_instances: Harvest GN Scatter for Per-Instance GLB Export
**Blender 5.1 | Holoflow Studio Library | scripting**

## What this is

A non-destructive Python technique for extracting every instance generated by a
Geometry Nodes scatter modifier into its own standalone `.glb` file — without
modifying the scene graph, without running `duplicates_make_real`, and without
collapsing everything into one monolithic mesh via Realize Instances.

The key primitive is `bpy.context.evaluated_depsgraph_get()`, which returns a
fully-evaluated dependency graph. Iterating `depsgraph.object_instances` exposes
every real object and every GN/particle/duplivert instance as a
`DepsgraphObjectInstance`, each with:

- `is_instance` — `True` for generated copies
- `matrix_world` — exact world placement matrix for this copy
- `parent` — the emitter object that generated it
- `random_id` — uint32 unique per instance; useful for variant/LOD selection

## Quick start

```python
# In Blender Scripting workspace
exec(open("/path/to/blueprint.py").read())
ground, prop = build_scene()
build_gn_tree(ground, prop)
count = harvest_instances("scatter_ground", pathlib.Path("//output/"), radius=6.0)
print(f"Exported {count} GLBs")
```

## World-space vs local-space strategy

**World-space bake** (default in blueprint.py):
`temp_mesh.transform(inst.matrix_world)` bakes placement into vertex positions.
Each `.glb` contains a mesh at its absolute scene position. Correct for offline
baked scenes where Three.js scene origin equals Blender world origin.

**Local-space** (for runtime instancing):
Skip `transform()`, set `temp_obj.matrix_world = inst.matrix_world` instead.
The `.glb` carries the matrix as a transform node. Three.js can share one
`BufferGeometry` across multiple `Object3D` — half the mesh memory.
