# Screen Recording Notes — Schwarzschild Geodesics Poi Disc

## Software

- **OBS Studio ≥ 30** (Windows / macOS / Linux — GPL-2.0, free at obsproject.com)
- Window source: **Blender 5.1**
- Resolution: **1920×1080** · Frame rate: **30 fps** · Audio: **off**

## Blender setup before recording

1. Run `blueprint.py` in the Scripting workspace.
2. Switch to **3D Viewport** → press **Z** → **Material Preview**.
3. Select `hf_schwarzschild_poi` and press **Numpad 7** (top-down view).
4. Press **Numpad .** to frame the selected object; zoom until the disc fills ~80 % of view.

## Tips

- On Windows: toggle the Blender system console via **Window → Toggle System Console**
  so the RK4 progress prints are visible during recording.
- Build takes ~20–45 s; let the `✓ Exported` line appear before cutting.
- Raise Viewport shading to **Rendered** (Z → Rendered) for the orbit segment;
  the emission shader makes the geodesic tubes glow against the dark world.
