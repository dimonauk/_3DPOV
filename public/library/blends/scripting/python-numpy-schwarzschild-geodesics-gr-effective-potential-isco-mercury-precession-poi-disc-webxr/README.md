# Schwarzschild Geodesics — GR Effective Potential, ISCO & Precessing Rosette Poi Disc

**Blender 5.1 · scripting · CC0**

Karl Schwarzschild derived the first exact solution to Einstein's vacuum field equations
in December 1915 — from the Russian front, weeks after Einstein published general
relativity.  The geodesics of his metric depart from Newtonian orbits by exactly the
amount needed to account for Mercury's 43″-per-century perihelion drift, and below
the Innermost Stable Circular Orbit (r=6M) no orbit is stable at all — a prediction
with no classical analogue.

This entry integrates a disc-shaped family of 36 equatorial Schwarzschild geodesics
via fourth-order Runge-Kutta, tubes each precessing rosette orbit with a hexagonal
cross-section, and assembles three orbital regimes as Blender shape keys.

## Key equations

```
d²r/dτ² = −M/r²  +  L²/r³  −  3ML²/r⁴      (GR correction: last term)
dφ/dτ   = L / r²

V_eff²(r,L) = (1 − 2M/r)(1 + L²/r²)          (effective potential)

r_isco  = 6M          L_isco = √12·M ≈ 3.464   E_isco = √(8/9) ≈ 0.9428

Δφ_prec ≈ 6πM / [a(1−e²)]  per orbit          (Mercury: 43.0″/century)
```
