# Raup Morphological Space — Mollusc Shell Coiling (Blender 5.1)

**Library path:** `public/library/blends/scripting/python-numpy-raup-mollusc-shell-morphospace-helicoidal-coiling-poi-head-webxr/`

## What this entry does

Implements David M. Raup's 1966 four-parameter helicoidal surface model that
maps virtually all known coiled-shell geometry into a single compact morphospace.
The blueprint constructs the surface in bpy via a vectorised NumPy meshgrid,
assigns four morphotype shape keys (Ammonite, Nautilus, Cone, Turritella), and
encodes whorl age as a magenta-to-cyan vertex colour gradient.  The output GLB
is sized to 0.12 m — standard Holoflow poi head — and ready for WebXR
morph-target animation.

## Parameters

| Symbol | Name | Range | Effect |
|--------|------|--------|--------|
| W | Whorl expansion rate | 1.2 – 5.0 | Low W → tight tower; high W → open disc |
| D | Umbilical ratio | 0.02 – 0.50 | Controls aperture size relative to coil radius |
| T | Translation rate | 0.0 – 4.0 | T=0 flat disc, T>2 tall spire |

## Files

## Outputs

- `hf_raup_shell.blend` — Blender file with all shape keys
- `hf_raup_shell.glb` — Draco-6 GLB for WebXR (export via Holoflow exporter)
- `viewport.mp4` — generated by `record.py` (Workbench vertex colour render)
- `screen.mp4` — captured via OBS per `SCREEN-RECORDING-NOTES.md`

## Quick start

1. Open Blender 5.1 → Scripting workspace
2. Load `blueprint.py` → press **Alt+P**
3. Verify: 7 200 vertices, 6 840 quads (NQ=180, NP=40, minus end row)
4. Load `record.py` → press **Alt+P**, then **Ctrl+F12**
5. Export GLB: File → Export → glTF 2.0 (Draco level 6, +Y up, apply transforms)
