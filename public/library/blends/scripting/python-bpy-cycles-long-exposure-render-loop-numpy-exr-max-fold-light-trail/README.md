# Cycles Long-Exposure Accumulation — Emissive Double-Helix Poi Trail

**Blender 5.1 · Holoflow Studio · CC0**

Simulates real-world long-exposure light-painting photography in Blender by
building an emissive double-helix scene, rendering 60 camera-orbit subframes
at Cycles 4 spp each, and folding them with `numpy.maximum` (MAX accumulation)
into a single composite image that shows the complete helix trail from every
angle simultaneously.

## Artefacts

## Technique

A long-exposure camera accumulates photons across the full shutter window.
`MAX` folding replicates the **peak-hold** behaviour of photographic film for
overbright emitters: any pixel that received strong emission in *any* subframe
retains that value in the final image.  The 60-step orbit (6° per step) ensures
every visible angle contributes to the composite.

`ADD` folding is also available (`ACCUM_MODE = 'ADD'`) and is more faithful to
true photon accumulation; it requires a normalisation step because the sum of 60
frames is 60× brighter than a single frame.

## Prerequisites

- Blender 5.1
- NumPy (bundled with Blender's Python since 2.93)
- Save the `.blend` file to the library directory before running so `//` paths resolve

## Usage

1. Open `blueprint.py` in the Scripting workspace and press **▶ Run Script**.
2. Inspect the scene (two NURBS helix strands, one camera, black world).
3. When ready, call `build_long_exposure()` from the Python Console or
   uncomment the last line of blueprint.py and re-run.

Approximate render time: 60 subframes × ~20 s/frame (Cycles, 4 spp, 960×540)
= about 20 minutes on a mid-range GPU.  Reduce `N_SUBFRAMES` or `CYCLES_SAMP`
for faster tests.
