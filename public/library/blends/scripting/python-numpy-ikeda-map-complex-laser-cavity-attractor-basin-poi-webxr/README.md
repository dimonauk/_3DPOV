# Ikeda Map — Complex Laser Cavity Attractor

**Blender 5.1 · Python + numpy · CC0**

The Ikeda recurrence z_{n+1} = a + b·z·exp(i·t(z)), t(z) = c − d/(1+|z|²)
models the complex field amplitude inside a ring laser with a Kerr-medium
nonlinear phase shift. For b ≥ 0.6 the map becomes chaotic; at b = 0.9 the
attractor is a fractal product of a Cantor set and a smooth curve — the same
topology that makes poi light-trail photographs look self-similar at every scale.

## Files

| File | Purpose |
|------|---------|
| `blueprint.py` | Run in Blender 5.1 Scripting workspace → builds mesh + GLB |
| `record.py` | Run after blueprint → renders 90-frame viewport animation |
| `SCREEN-RECORDING-NOTES.md` | OBS instructions for screen.mp4 |
| `hf_ikeda.glb` | Generated — WebXR-ready GLB with 3 shape keys |
| `viewport.mp4` | Generated by record.py |
| `screen.mp4` | Recorded manually via OBS |

## Quick start

1. Open Blender 5.1 → Scripting workspace.
2. Paste or load `blueprint.py`. Run it (Alt+P or ▶).
3. Inspect the 120×120 quad mesh in the 3D Viewport.
4. Drag the three shape keys (`b=0.70`, `b=0.85`, `b=0.92`) to explore
   the bifurcation from period-2 limit cycle through edge-of-chaos to
   full strange attractor.
5. Run `record.py` to bake the animation and write `viewport.mp4`.
