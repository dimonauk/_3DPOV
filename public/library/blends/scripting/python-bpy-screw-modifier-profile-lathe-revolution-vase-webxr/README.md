# ScrewModifier — Profile-to-Lathe Revolution (Blender 5.1)

**Slug:** `python-bpy-screw-modifier-profile-lathe-revolution-vase-webxr`
**Blender:** 5.1 · **Licence:** CC0 · **Topic:** scripting

## What this tutorial teaches

`bpy.types.ScrewModifier` revolves a 2D profile mesh (vertices + edges in a
plane containing the rotation axis) around that axis to produce a surface of
revolution — the technique potters call a lathe and mathematicians call a
surface of revolution.  The result is a watertight, faceted, 12-gon vase
ready for Draco-compressed GLB export.

Key concepts:

- Why the profile must contain **edges**, not bare vertices
- How `steps` controls the angular facet count (4 = square cross-section, 12 = dodecagonal)
- `use_merge_vertices` at `angle=2π` — closing the seam without a visible crease
- `screw_offset > 0` turns the revolution into a helix (screws, springs)
- Headless baking via `evaluated_get() + new_from_object()` (no `bpy.ops`)
- Blender 5.1 sharp-edge attribute API for faceted GLB normals
