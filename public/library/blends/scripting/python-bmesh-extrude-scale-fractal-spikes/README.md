# python-bmesh-extrude-scale-fractal-spikes

**Blender 5.1 · CC0 · scripting topic**

Fractal spike-ball built entirely via the bmesh direct-data API.  An
ICO sphere (level 2, 80 triangles) is grown into a tiered spike structure
by iterating `bmesh.ops.extrude_discrete_faces` four times.  Each pass
extrudes every tip cap independently, translates the new cap up along its
face normal, and scales it toward its own centre — creating a tapered
sub-spike proportionally smaller than its parent.

## Files

| File | Description |
|---|---|
| `blueprint.py` | Full build + GLB export script (run in Scripting workspace) |
| `record.py` | EEVEE render of the 360° spin animation |
| `SCREEN-RECORDING-NOTES.md` | OBS/Game Bar instructions for `screen.mp4` |
| `fractal_spike_ball.blend` | Generated by blueprint.py |
| `fractal_spike_ball.glb` | Draco L6 + WebP, Y-up, studio-ready |

## Running

1. Open Blender 5.1 → Scripting workspace → New text block.
2. Open `blueprint.py` → **Run Script**.
3. The `.blend` and `.glb` appear in this directory.
4. To render the video: open `fractal_spike_ball.blend` → open `record.py` → Run Script.

## Parameters (top of blueprint.py)

| Constant | Default | Effect |
|---|---|---|
| `ICO_SUBDIVISIONS` | 2 | Base sphere detail (level 3 = 320 faces, visually dense) |
| `ITERATIONS` | 4 | Spike generations; each adds one tier of sub-spikes |
| `EXTRUDE_FACTOR` | 0.90 | Multiplier on sqrt(face_area) → spike height |
| `SCALE_FACTOR` | 0.58 | Cap contraction per iteration; 0.5 = half-size tips |

## Topology

With defaults (ICO L2, 4 iterations):

- Original sphere: 80 triangles
- Each iteration adds 80 cap triangles + 80 × 3 side quads = 320 faces
- Total after 4 iterations: 80 + 4 × 320 = **1 360 faces**

## Key technique

`extrude_discrete_faces` is the critical choice over `extrude_face_region`:
the discrete operator lifts each face as an isolated unit, leaving the gap
between adjacent spike bases open.  The region operator would join adjacent
face edges into a continuous dome.
