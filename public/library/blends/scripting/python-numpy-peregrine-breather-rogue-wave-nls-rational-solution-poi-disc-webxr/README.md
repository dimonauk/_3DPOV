# Peregrine Breather — Doubly-Localised Rogue Wave (Blender 5.1)

## What this is

A Blender 5.1 height-field poi disc encoding the **Peregrine breather** — the
exact rational solution to the focusing 1D Nonlinear Schrödinger (NLS) equation
discovered by Howell Peregrine in 1983.

The surface shows `|Ψ_P(x,t)|` over the x–t plane, where x is the spatial
coordinate and t is time. Vertex colours map cobalt (background amplitude 1) →
amber (amplitude 2) → crimson (rogue peak amplitude 3).

## Key mathematics

```
NLS:     i Ψ_t + ½ Ψ_xx + |Ψ|² Ψ = 0

Ansatz:  Ψ_P(x,t) = [1 − 4(1+2it)/D(x,t)] · e^{it}
         D(x,t)   = 1 + 4x² + 4t²

|Ψ_P|²  = [(D−4)² + 64t²] / D²

Peak:    |Ψ_P(0,0)| = 3   (exact, no free parameters)
Decay:   |Ψ_P(x,t)| → 1  as (x,t) → ∞  (algebraically, not exponentially)
```

The `3:1` amplitude ratio is universal — it holds for any background amplitude
once the equation is normalised, which is why it became the canonical model for
ocean rogue waves.
