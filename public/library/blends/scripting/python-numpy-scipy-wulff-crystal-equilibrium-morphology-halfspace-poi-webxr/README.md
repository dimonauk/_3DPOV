# Wulff Crystal — Equilibrium Morphology via Halfspace Intersection

**Blender 5.1** · **CC0** · scripting · Python + NumPy + SciPy

---

## What this is

G. Wulff (1901) proved that the crystal shape minimising surface energy
∫ γ(n̂) dA at fixed volume is the intersection of halfspaces:

```
W = ∩_{n̂} { x ∈ ℝ³ : n̂·x ≤ γ(n̂) }
```

This blueprint generates a **cubic Wulff crystal poi head** with five shape
keys sweeping the complete {100}/{111} morphological phase diagram:

| Shape key | d₁₁₁/d₁₀₀ | Crystal form |
|-----------|-----------|--------------|
| `cube` | 1.90 > √3 | Pure cube — only {100} faces |
| `trunc_cube` | 1.35 | Cube corners bevelled by {111} |
| `cuboctahedron` | 1.155 = 2/√3 | Equal {100} + {111} faces |
| `trunc_octa` | 0.80 | Truncated octahedron — dominant {111} |
| `octahedron` | 0.577 ≈ 1/√3 | Pure octahedron — only {111} faces |

## Key algorithm

```
r(u) = min_{i : n̂ᵢ·u > 0}  dᵢ / (n̂ᵢ·u)
```

Projects a level-2 icosphere (162 verts) radially onto the Wulff surface.
Each projected vertex lies exactly on a planar crystal face.  Flat shading
groups coplanar triangles into apparent gem facets.  Same topology across
all shape keys → Blender shape keys work without restriction.
