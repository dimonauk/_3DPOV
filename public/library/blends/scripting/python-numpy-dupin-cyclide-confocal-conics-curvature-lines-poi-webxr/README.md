# Dupin Cyclide: Confocal Conic Curvature Lines, Torus Inversion & Three-Morphotype Poi Head

**Topic:** scripting | **Blender:** 5.1 | **Licence:** CC0

## What this is

A **Dupin cyclide** is the unique algebraic surface in ℝ³ (degree 4) whose
two families of principal curvature lines are both made entirely of circles.
Pierre Charles François Dupin proved this property in 1822 as a consequence
of his work on canal surfaces — surfaces that can be swept out as the
envelope of a one-parameter family of spheres.

Every standard ring torus is a Dupin cyclide. The full family also includes
*horn cyclides* (one singular point) and *spindle cyclides* (self-intersecting
lens shapes). All three types are related by Möbius (sphere-inversion)
transformations in ℝ³.

## Running the blueprint

1. Open Blender 5.1.
2. Open `blueprint.py` in the Scripting workspace.
3. Press **Run Script** (`Alt + P`).
4. The cyclide appears at origin; shape keys `Torus`, `Horn`, `Spindle`
   are available in Properties → Object Data → Shape Keys.

## Mathematics: the 5-4-3 parametrisation

```
a = 5,  b = 4,  c = 3   (Pythagorean: a² = b² + c²)
denom = a − c cos u cos v

x = (d(c − a cos u cos v) + b² cos u)  / denom
y = b sin u (a − d cos v)               / denom
z = b sin v (c cos u − d)               / denom
```

| Shape key | d value | Type |
|-----------|---------|------|
| Basis (ring) | 1.5 | ring cyclide — smooth closed surface |
| Torus | 0.05 | near-torus (d → 0 limit) |
| Horn | 3.0 (= c) | cuspidal point at (b²/a, 0, 0) |
| Spindle | 4.7 (> c) | self-intersects along two circles |
