# Chen-Lee Attractor (2004) — Rigid-Body Euler Equations with Linear Anti-Control

**System**: H.K. Chen & C.I. Lee, "Anti-control of chaos in rigid body motion," *Chaos, Solitons & Fractals* 21(4):957-965, 2004.  
**Equations**: Public domain (mathematical objects).  
**Blender**: 5.1  
**Licence**: CC0

## Equations

```
ẋ = a·x − y·z
ẏ = b·y + x·z
ż = c·z + x·y / 3
```

Canonical parameters: **a = 5**, **b = −10**, **c = −0.38**

## Background

Euler's equations for a freely rotating rigid body are area-preserving — they never produce chaos on their own.  Chen & Lee (2004) added linear feedback to deliberately drive the system into chaotic motion.  The *anti-control* perspective is unusual: instead of finding chaos and trying to suppress it, they engineered chaos into an integrable system.

The nonlinear terms (y·z, x·z, x·y/3) are the exact Euler torques; the linear terms (a·x, b·y, c·z) are the engineered pumping and damping.  The resulting geometry is physically interpretable: the four off-origin fixed points represent unstable equilibrium attitudes of the body, and the attractor threads between them.
