# bmesh.ops.grid_fill — Structured Quad Fill for a Hard-Surface Display Panel

**Blender 5.1 · Python scripting · Hard-surface prop · WebXR GLB**

`bmesh.ops.grid_fill` closes a rectangular hole in a mesh with a clean
N×M quad patch. It is the context-free equivalent of Blender's interactive
**Grid Fill** tool (F key in Edge select mode with a structured loop selected).

## What this blueprint builds

A sci-fi terminal display panel (`hf_grid_fill_display.glb`) comprising:

| Component | Technique | Result |
|-----------|-----------|--------|
| Outer bezel ring | 8×6 grid minus 6×4 centre | 24 bezel quads, metallic grey material |
| Screen patch | `bmesh.ops.grid_fill` on the 20-edge hole boundary | 24 screen quads, teal emission material |
| Chassis body | `bmesh.ops.extrude_face_region` + translate | 100 mm deep solid panel |

## Key concepts

- **`grid_fill` requires a rectangular boundary**: opposing rail pairs must have
  equal edge counts (`top == bottom`, `left == right`). Violating this returns
  an empty `result['faces']` with no Python exception raised.
- **Collect hole edges BEFORE deleting inner faces**: the `Counter`-based boundary
  detection approach records which edges sit on the screen perimeter while the
  screen faces still exist, preventing the need for post-deletion edge queries.
- **`context='FACES'` delete**: removes the face geometry AND interior dangling
  edges/verts, leaving a clean hole with a closed boundary loop.
- **`use_interp_simple=False`** (default): cubic Bezier interpolation between
  opposing rails — on flat panels identical to linear, but the correct default
  for curved surfaces.
