## What this makes

A 256 × 256 height-field quad mesh that reproduces the patterns Ernst Chladni
observed when bowing a sand-covered metal plate.  Each vertex is coloured by
the phase of the standing-wave displacement (cyan = positive antinode,
magenta-pink = negative antinode, white = nodal line) and raised proportionally
to the amplitude |ψ|.  Nodal lines appear as valleys — the physical locations
where sand collects.

Two morph targets let you transition between three Chladni modes at runtime:

| Shape key | Mode | Lobes | Symmetry |
|-----------|------|-------|----------|
| Basis | ψ⁺(2,3) | 12 | ≈ D₄ |
| mode_1_2_plus | ψ⁺(1,2) | 4 | D₄ diagonal cross |
| mode_3_4_minus | ψ⁻(3,4) | 24 | D₂ starburst |

## Quick start

1. Launch Blender 5.1.
2. Switch to **Scripting** workspace.
3. Open `blueprint.py`, press **Alt+P**.  
   Console prints `[chladni] ✓ exported //hf_chladni.glb` (~8 s on 8 cores).
4. Open `record.py`, press **Alt+P** to render `viewport.mp4` (90 frames).
5. File → Save As → `hf_chladni.blend`.

## Mathematics

For x,y ∈ [−1,1] on a square plate, mode (m,n) with superposition sign s ∈ {±1}:

```
ψ(m,n,s,x,y) = cos(mπx)·cos(nπy)  +  s·cos(nπx)·cos(mπy)
```

Nodal lines: {ψ = 0}. Sand migrates there due to acoustic radiation pressure
pushing grains away from regions of high displacement gradient. The height
field maps z = |ψ| × 0.35 m so ridges mark antinodes and valleys mark nodes.
