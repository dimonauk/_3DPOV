# Phyllotaxis — Golden Angle Spiral, Fibonacci Parastichies & Torus Lattice

**Blender 5.1 | Python scripting | CC0 | Holoflow Studio**

## What this is

Two sculptures generated by the single mathematical principle that governs
sunflower seeds, pine-cone scales, and pineapple diamonds:

**DISK** — A 500-floret Vogel sunflower (Vogel 1979) in the XY plane.
Each floret n sits at polar radius r = C·√n and angle θ = n·α, where
α = 2π/φ² ≈ 137.508° is the golden angle. The result shows 13 and 21
Fibonacci spiral arms — consecutive members of the Fibonacci sequence.

**TORUS** — A 300-floret golden-angle lattice on a torus surface. Azimuthal
position v = n·α and poloidal position u = n·α/φ. Weyl's equidistribution
theorem (1916) guarantees uniform coverage because α/φ is irrational.

## Key mathematics

```
α = 2π/φ²  ≈  137.508°            (golden angle)
φ = (1+√5)/2 ≈ 1.61803             (golden ratio)
r(n) = C·√n                        (equal-area radial law, Vogel 1979)
θ(n) = n·α                         (golden-angle rotation)

Torus:
  v(n) = n·α     (azimuthal)
  u(n) = n·α/φ   (poloidal — equidistributed by Weyl 1916)
```
