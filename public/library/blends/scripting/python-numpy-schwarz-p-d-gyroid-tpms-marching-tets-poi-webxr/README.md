# Schwarz P, D & Gyroid — Triply-Periodic Minimal Surfaces (Blender 5.1)

Three poi heads generated by Marching Tetrahedra on implicit TPMS functions.

## Surfaces

| Name | Implicit equation | Space group | θ (Bonnet) |
|---|---|---|---|
| Schwarz P | cos x + cos y + cos z = 0 | Pm-3m | 0° |
| Schoen Gyroid | sin x cos y + sin y cos z + sin z cos x = 0 | I4₁32 | 38.015° |
| Schwarz D | sin x sin y sin z + sin x cos y cos z + cos x sin y cos z + cos x cos y sin z = 0 | Fd-3m | 90° |

All three are minimal (H = 0 everywhere).  The Gyroid is chiral — no mirror
planes or inversion centre.  It appears in butterfly wing nanostructures
(*Callophrys rubi*), lipid bicontinuous phases, and 3D-printed scaffolds.

## Algorithm

Marching Tetrahedra (Doi & Koide 1991): each cube in the N³ grid is split
into 6 tetrahedra sharing the body-diagonal edge.  Each tet has at most 3
topologically distinct cases (vs. 14 in Lorensen–Cline Marching Cubes 1987),
making the implementation table-free.

## Running

1. Open Blender 5.1, new General file.
2. Switch to the **Scripting** workspace.
3. Open `blueprint.py`, press **Run Script**.
4. Three poi-head objects appear: `schwarz_p` (left), `gyroid` (centre), `schwarz_d` (right).
5. GLB is exported to the same directory as the `.blend` file.

N=32 (default) takes roughly 8–15 seconds on a modern CPU.  Increase to N=48
for smoother surfaces; the sparse active-cell filter keeps the cost reasonable.
