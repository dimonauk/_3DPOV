# Thomas Cyclically Symmetric Attractor (René Thomas, 1999)

**Sine Nonlinearity · C₃ Cyclic Symmetry · Shilnikov Wings · Bishop Tube + Poi · WebXR**

---

## System

```
ẋ = sin(y) − b·x
ẏ = sin(z) − b·y
ż = sin(x) − b·z
```

C₃ cyclic symmetry: the cyclic permutation σ:(x,y,z)→(y,z,x) maps each
equation to the next — the system is identical under this rotation.

**Canonical parameter:** b = 0.208 (Thomas 1999)

## Why Sine Nonlinearity Matters

Unlike polynomial attractors (Lorenz: xy, xz; Sprott: y², yz), sine
nonlinearity is globally bounded — |sin(·)| ≤ 1. This means:

1. The attractor exists for **any b > 0** without a separate proof of
   global boundedness (polynomial systems need Lyapunov functions).
2. As b → 0, the system approaches Hamiltonian (volume-preserving), and
   the orbit can explore a periodic lattice of near-Hamiltonian cells —
   Thomas's "labyrinthine chaos".
3. The forcing term is **smooth and periodic** — ideal for Fourier analysis
   and Poincaré section reconstruction.

## Shilnikov Mechanism

The chaotic orbit winds around the symmetric fixed points
P± ≈ (±2.661, ±2.661, ±2.661), not the origin. At each P±:
- Stable real eigenvalue: λ_s ≈ −1.086 (attracting)
- Unstable complex pair: λ_c ≈ 0.231 ± 0.760i (repelling spiral)

Because |λ_s| = 1.086 > Re(λ_c) = 0.231, the **Shilnikov condition** is
met: each return to the neighbourhood of P± generates a new chaotic scroll.
The c₃ symmetry means P+ and P− contribute identically but independently
— the attractor has a single connected lobe (not a two-scroll butterfly)
because both wings share the same basin.
