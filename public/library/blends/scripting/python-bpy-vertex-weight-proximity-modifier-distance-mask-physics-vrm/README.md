# VertexWeightProximityModifier — Distance-Driven Weight Mask

**Blender 5.1 · holoflow_webxr_exporter · CC0**

Computes vertex group weights from distance to a target object's surface,
then feeds those weights into a Cloth modifier as a pin group. Vertices
close to the body proxy are pinned (weight ≈ 1.0); vertices beyond `max_dist`
drape freely (weight ≈ 0.0).

## Key insight

`VertexWeightProximityModifier` is a **Modify** modifier: it writes vertex
data, not geometry. Blender's modifier evaluation order is:

```
Modify → Generate → Deform → Physics
```

Proximity weights are therefore always fresh when Cloth reads its pin group —
animate the target sphere and the pinned region tracks it live.

## Quick start

```python
# 1. Create a vertex group on your mesh
sash.vertex_groups.new(name="prox_pin")

# 2. Add the modifier
mod = sash.modifiers.new("VWProx", "VERTEX_WEIGHT_PROXIMITY")
mod.vertex_group       = "prox_pin"
mod.target             = body_sphere
mod.proximity_mode     = "GEOMETRY"   # distance to nearest surface point
mod.proximity_geometry = {"FACE"}     # sample against face planes
mod.min_dist           = 0.0          # flush = weight 1.0
mod.max_dist           = 0.22         # beyond = weight 0.0
mod.falloff_type       = "SMOOTH"     # C¹ Hermite between min/max
mod.normalize          = True

# 3. Wire the vertex group to cloth pin
cloth = sash.modifiers.new("Cloth", "CLOTH")
cloth.settings.use_pin_cloth     = True
cloth.settings.vertex_group_mass = "prox_pin"
cloth.settings.pin_stiffness     = 1.0
```

## Gotchas

- `proximity_geometry = {'VERTEX'}` samples only vertex positions on the
  target, not the surface itself. On a sphere, this underestimates distance
  in regions between vertices. Always prefer `{'FACE'}` for closed meshes.
- `min_dist` / `max_dist` are measured in **world space** after applying
  transforms. If your body sphere is scaled to 2× and you set `max_dist=0.2`,
  the effective threshold is at 0.2 m world distance from the scaled sphere.
- `normalize = True` clamps the heaviest weight in the group to 1.0. Only
  matters if ALL vertices are beyond `max_dist` (all zero → no change) or
  if `invert_falloff = True` and you want the furthest vertex at 1.0.
- `mask_vertex_group` acts as a secondary multiplier:
  `final = proximity_weight × mask_weight`. Use it to restrict pinning to
  a collar region while leaving shoulder geometry free.
