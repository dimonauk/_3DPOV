# Screen Recording Notes — Magnetic Pendulum Fractal Basin

## Overview
These are the instructions for capturing `screen.mp4` using OBS Studio or Windows
Game Bar.  The viewport animation is generated by `record.py` and saved as
`viewport.mp4`; `screen.mp4` is the supplementary recording of the interactive
session — useful as tutorial footage showing the workflow in the Blender UI.

---

## Recommended capture setup (OBS Studio)

| Setting              | Value                             |
|----------------------|-----------------------------------|
| Source               | Window capture → Blender 5.1      |
| Resolution           | 1920 × 1080                       |
| Frame rate           | 30 fps                            |
| Audio                | Off (no microphone needed)        |
| Output format        | MP4 (H.264 High)                  |
| Bitrate              | 8 000 kbps                        |
| Output file          | `screen.mp4` in this folder       |

---

## Suggested recording sequence (≈ 5–8 minutes)

1. **Open Blender** — new general scene, maximise the viewport.
2. **Scripting workspace** — paste `blueprint.py` into the Text Editor.
   - Explain the grid parameters at the top (GRID_N, GRID_EXTENT, magnets).
   - Run the script. Show the terminal output as simulations print progress.
3. **While the script runs (≈ 2–3 min)** — switch to the spreadsheet and show
   the grid vertex count (14 400 V).
4. **After completion** — rotate the viewport:
   - Numpad 7 → top view to show the basin colour map.
   - Numpad 4/6 → side view to show the fractal height ridges.
   - Middle-mouse orbit to inspect the ridge detail near basin boundaries.
5. **Shape key sweep** — in Properties ▸ Object Data ▸ Shape Keys, scrub each
   key (SK_HighDamp → smoother, SK_LowDamp → more intricate, SK_4Mag → 4
   magnet square layout).
6. **Material check** — switch the viewport to Rendered or Material Preview to
   show the cobalt/amber/violet colour attribution.
7. **Close** — optionally run `record.py` and note the output path.

---

## Windows Game Bar alternative

- Win + G → open Game Bar → Capture → Record.
- Clip the Blender window.
- Settings match OBS recommendations above.
