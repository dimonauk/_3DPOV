# Screen Recording Notes — 600-Cell Stereographic Shadow

## OBS / Game Bar settings

| Setting | Value |
|---------|-------|
| Source | Window Capture → Blender |
| Resolution | 1920 × 1080 |
| Frame rate | 30 fps |
| Audio | Disabled |
| Output file | `screen.mp4` (place alongside `viewport.mp4`) |

## Session flow to capture

1. Open Blender 5.1. Set layout to **Scripting** workspace.
2. In the Text Editor, open `blueprint.py`.
3. Press **Run Script** (▶). Console prints vertex count (120) and edge count (720).
4. Switch to **3D Viewport**. The projected 600-cell appears — nested glowing arcs.
5. Orbit slowly around the object with middle-mouse drag. Zoom to show inner shells.
6. Switch to **Rendered** viewport shading to show the emissive violet edges against the black world.
7. Press `Numpad 0` to enter Camera view. Show the framed composition.
8. Optionally: open the Python console and type:
   ```python
   import bpy, numpy as np
   ob = bpy.data.objects["hf_600cell"]
   print(len(ob.data.vertices), len(ob.data.edges))
   ```
   to show the live vertex/edge count on screen.
9. Stop recording. Trim to 60–90 seconds.

## What makes a good take

- Start with the full polytope visible in **Solid** shading so the mesh topology is clear.
- Switch to **Rendered** mid-recording for the dramatic reveal of the glowing arcs.
- Zoom into the inner cells to show the compressed dodecahedral shells.
- Briefly show the Script editor to demonstrate that the entire geometry is generated by Python.
