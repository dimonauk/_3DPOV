# Riemann Zeta Function — Critical Strip Stage Floor

**Blender 5.1 · Python + NumPy · CC0 · Holoflow Studio**

A stage-floor height field built from the modulus surface |ζ(σ+it)|, computed
via Euler–Maclaurin summation on an 80×160 grid covering σ∈[0.02, 0.98] and
t∈[0.5, 50].  Height encodes log(1+|ζ|); vertex colour encodes arg(ζ) via an
HSV rainbow.  A gold polyline marks the critical line σ=½; five red cylinders
mark the first five non-trivial zeros.

## What you see

- **Height field** — h = clip(log(1+|ζ(σ+it)|), 0, 2.8) × 0.18 m.
  Tall ridges near σ=1, t→0 trace the approach to the simple pole at s=1.
- **HSV vertex colour** — hue = arg(ζ)/(2π)+½ cycles through the rainbow;
  saturation drops to grey near zeros where |ζ|→0.
- **Gold spine** — marks the critical line σ=½; the functional equation
  ξ(s)=ξ(1−s) means the height field is mirror-symmetric about this line.
- **Red cylinders** — five non-trivial zeros at Im(s) ≈ 14.13, 21.02,
  25.01, 30.42, 32.94.  The Riemann Hypothesis asserts *all* non-trivial zeros
  lie on this line — unproved since 1859.
- **Euler product** — ζ(s) = Π_p(1−p^{-s})^{-1}; the height ridge along
  σ=1 reflects the product's divergence as s→1⁺.

## Mathematical background

| Concept | Formula |
|---|---|
| Dirichlet series | ζ(s) = Σ_{n≥1} n^{-s}, Re(s) > 1 |
| Euler product | ζ(s) = Π_p (1−p^{-s})^{-1}, Re(s) > 1 |
| Functional equation | ξ(s) = ξ(1−s) where ξ(s) = ½s(s−1)π^{-s/2}Γ(s/2)ζ(s) |
| Trivial zeros | s = −2, −4, −6, … |
| Critical strip | 0 < Re(s) < 1, location of non-trivial zeros |
| Riemann Hypothesis | All non-trivial zeros have Re(s) = ½ |
