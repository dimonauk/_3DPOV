# Lozi Map (1978) — Piecewise-Linear Strange Attractor, Log-Density Height-Field

**René Lozi 1978 / Misiurewicz proof 1980 · Blender 5.1 · CC0**

The first 2-D invertible map whose strange attractor was proved rigorously,
rendered as a 120 × 120 log-density height-field stage floor for WebXR.

---

## The mathematics

```
x_{n+1} = 1 − a · |x_n| + y_n
y_{n+1} = b · x_n
```

The Lozi map is the **piecewise-linear analogue of the Hénon map**.  Replace
Hénon's smooth `x²` fold with the V-shaped `|x|` tent fold.  The qualitative
topology is the same — a horseshoe-type strange attractor — but the analysis
becomes tractable because the Jacobian is piecewise-constant:

| Region | Jacobian | det J |
|--------|----------|-------|
| x > 0 | `[[-a,1],[b,0]]` | −b |
| x < 0 | `[[+a,1],[b,0]]` | −b |

`|det J| = b` **everywhere**.  Constant dissipation gives Misiurewicz explicit
hyperbolicity bounds, enabling the 1980 proof — 11 years before Benedicks and
Carleson proved an analogous result for the Hénon map.

## Blender 5.1 API notes

- Uses `bpy.data.meshes.from_pydata()` — context-free, safe in headless mode.
- Colour attribute type `FLOAT_COLOR` on `POINT` domain preserves HDR range
  for EXR bakes and WebXR export.
- Shape keys added via `obj.shape_key_add()` + `foreach_set("co", …)` rather
  than `bpy.ops` — avoids context dependency.
