# Penrose P3 Rhombus Tiling — Robinson Triangle Deflation

**Blender 5.1 · Python + NumPy · Stage Floor · WebXR GLB**

A circular stage-floor disc tiled with Penrose P3 rhombuses generated by
Robinson triangle deflation. Two tile shapes — fat (72°/108°, gold) and thin
(36°/144°, crimson) — fill the plane aperiodically while exhibiting approximate
five-fold local symmetry. The disc is exported as a Draco-compressed GLB ready
for the studio's WebXR pipeline.

## Quick start

```bash
# In Blender 5.1 Scripting workspace:
# 1. Open blueprint.py in the Text Editor
# 2. Click "Run Script"
# 3. Object "penrose_p3_floor" appears in the scene
# 4. penrose_p3_floor.glb written alongside the .blend file
```

## Parameters (top of blueprint.py)

| Name | Default | Effect |
|------|---------|--------|
| `DEFLATION_STEPS` | 5 | Number of Robinson subdivisions. 4 → ~130 tiles; 5 → ~450; 6 → ~1 800. |
| `DISC_RADIUS` | 2.6 | Clip radius in Blender units. |
| `SLAB_FAT` | 0.060 | Extrusion height for fat (gold) rhombuses. |
| `SLAB_THIN` | 0.040 | Extrusion height for thin (crimson) rhombuses. |
| `INSET` | 0.945 | Tile shrink factor. 1.0 = no gap; 0.9 = 10 % gap all round. |

## Key mathematical facts

- **Two tile types:** fat rhombus (angles 72°/108°, area φ times thin) and thin
  rhombus (angles 36°/144°).  Together they tile the plane in infinitely many
  distinct aperiodic patterns.
- **Golden ratio scale:** each Robinson deflation shrinks tiles by 1/φ.  After
  N steps the tile edge = φ^{−N} seed edges.  DISC_RADIUS = 2.6 at N = 5 gives
  edges ≈ 0.28 Blender units.
- **Aperiodicity:** Penrose proved (1974) there is no period cell — any region
  of the tiling, however large, reappears elsewhere without translation
  periodicity.
- **Five-fold symmetry:** the tiling is not five-fold symmetric globally, but
  every finite patch has a five-fold symmetric patch containing it (Conway &
  Radin, 1998).  The "sun" seed we use gives the most visually prominent
  approximate five-fold centre.
