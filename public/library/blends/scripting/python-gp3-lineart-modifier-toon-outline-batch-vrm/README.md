# GP3 Line Art Modifier — Batch Toon Outline for VRM (Blender 5.1)

Scripted Grease Pencil 3 Line Art modifier setup across a multi-object VRM proxy scene.  Demonstrates per-object `lineart.usage` flags, `crease_threshold` tuning, intersection masking, and layer targeting — the parameters needed to reproduce a consistent toon outline across every character in a VRM library.

## Files

| File | Purpose |
|---|---|
| `blueprint.py` | Full production script — builds scene, configures modifier, saves .blend + manifest |
| `record.py` | Renders 3-second turntable to `viewport.mp4` via OpenGL capture |
| `SCREEN-RECORDING-NOTES.md` | OBS chapter plan for the screen recording |
| `.expected-artefacts.json` | CI artefact manifest |

## Generated artefacts

- `gp3_lineart_vrm_proxy.blend` — scene with body/head mesh + GP3 ink object
- `gp3_lineart_vrm_manifest.json` — modifier settings + per-object usage table
- `viewport.mp4` — 72-frame turntable (generated by `record.py`)
- `screen.mp4` — OBS screen capture (generated by the human operator)

## Key Blender 5.1 API points

```python
# Modifier type string — changed from GP_LINEART in Blender < 4.3
gp_ob.modifiers.new("LineArt", "GREASE_PENCIL_LINEART")

# Per-object opt-in
ob.lineart.usage = "INCLUDE"  # | "EXCLUDE" | "INHERIT" | "FORCED_INCLUDE"

# Crease threshold in RADIANS (UI shows degrees)
import math
la.crease_threshold = math.radians(140)

# GP material bootstrap — must call before setting .grease_pencil properties
bpy.data.materials.create_gpencil_data(mat)

# Intersection mask — 1-byte bitmask per object
body.lineart.intersection_mask = 0b00000001
head.lineart.intersection_mask = 0b00000010
```
