# bmesh.ops.subdivide_edges — Architectural Plinth: Support Loops, Fractal Stone & INNER_VERT Panel

**Blender 5.1 · Python scripting · CC0**

Three production patterns for `bmesh.ops.subdivide_edges` — the headless, context-free alternative to the W → Subdivide operator:

| Object | Mode | Use case |
|---|---|---|
| `hf_sub_cap` | `STRAIGHT_CUT cuts=2` on vertical edges only | SubD support loops |
| `hf_sub_shaft` | `fractal=0.055 seed=7` on all edges | Procedural stone noise |
| `hf_sub_base` | `INNER_VERT cuts=1` on top-face perimeter | Recessed panel inset |

## Running

```bash
blender --background --python blueprint.py
```

Or open Blender 5.1, open `blueprint.py` in the Text Editor, press `Alt+P`.

## Key Insights

- `subdivide_edges` returns `geom_inner` (new interior geometry) and `geom_split` (sub-edge segments replacing originals). Filter `geom_inner` for `isinstance(e, BMEdge)` to find the new loop rings.
- `fractal` amplitude is multiplied by **edge length** — use `cuts=3` to shorten sub-edges before applying noise, otherwise a 1-unit box edge can produce 5+ cm displacement at `fractal=0.05`.
- `INNER_VERT` places a centre vert inside each quad patch; for a single quad with all 4 edges cut once this produces a 4-triangle star fan — visually equivalent to `bmesh.ops.poke` but controllable via `smooth=`.
- `seed=0` is NOT random — it is Blender's fixed internal default seed. Use a non-zero seed for deterministic results across runs.
