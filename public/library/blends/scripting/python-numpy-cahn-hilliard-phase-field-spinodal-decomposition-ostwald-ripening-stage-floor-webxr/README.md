# Cahn–Hilliard Phase-Field Spinodal Decomposition

**Blender 5.1 | Python + numpy | Stage floor for WebXR**  
**Licence**: CC0 (equations public domain >65 yr; code original)

---

## What this is

A 128 × 128 height-field stage floor generated by integrating the
**Cahn–Hilliard equation** — the canonical 4th-order PDE for phase separation
in binary mixtures. A single conserved composition field c(x,y,t) ∈ [0,1]
evolves spontaneously from a noisy homogeneous state into micro-domains:

- **Labyrinthine patterns** at symmetric composition c̄ = 0.5
- **Isolated droplets** at minority composition c̄ = 0.3
- **Ostwald ripening** — large domains absorb small ones over time

Vertex height encodes composition (z = c × 0.4 m). Vertex colour
(FLOAT_COLOR attribute `CH_Comp`) maps cobalt (c = 0) → amber (c = 1).

---

## Mathematics

```
∂c/∂t = M ∇²μ            (conservation: ∂/∂t ∫c dV = 0)
μ      = f'(c) − ε² ∇²c  (chemical potential)
f(c)   = c²(1−c)²/4      (double-well Landau free energy)
f'(c)  = c(1−c)(2c−1)    (drives c toward 0 or 1)
```

Spinodal instability: d²f/dc² < 0 when 1/3 < c < 2/3.  
Unlike nucleation, any infinitesimal perturbation grows in this band.

**Numerical method**: FFT semi-implicit (Eyre 1998):
```
ĉ(t+dt) = [ĉ(t) − dt·M·k²·F̂{f'(c)}] / (1 + dt·M·ε²·k⁴)
```
Unconditionally stable — no CFL constraint despite the k⁴ stiffness.

## Parameters

| Constant | Value | Role |
|---|---|---|
| N | 128 | Grid resolution (128 × 128 = 16 384 vertices) |
| M | 1.0 | Mobility |
| ε (basis) | 0.030 | Interface thickness |
| ε (thick) | 0.050 | Softer walls |
| DT | 0.25 | Time step |
| c̄ (basis) | 0.50 | Symmetric: labyrinthine |
| c̄ (droplets) | 0.30 | Minority phase: isolated droplets |
| STEPS_EARLY | 120 | Basis — early-stage separation |
| STEPS_COARSE | 600 | SK_Coarsened — Ostwald ripening |

## Shape keys

| Key | Physics |
|---|---|
| Basis | Early spinodal: thin interconnected channels |
| SK_Coarsened | Late-stage: large coarsened domains (Ostwald ripening) |
| SK_Droplets | Minority composition: isolated droplets on sea of c≈0 |
| SK_ThickInterface | ε = 0.05: broad, diffuse domain walls |
