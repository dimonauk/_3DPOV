# BuildModifier — Z-Sorted Face-Reveal Crystal Growth

**Blender 5.1 · CC0 · Holoflow Studio**

`bpy.types.BuildModifier` reveals mesh faces over time by suppressing them in
the evaluated mesh. Unlike visibility keyframes or shape-key toggling, Build
operates at the modifier level: downstream modifiers and the renderer never see
hidden faces at all, so there are no ghost shadows or z-fighting artefacts
during the growth sequence.

The craft of this tutorial is **controlling reveal order**. In sequential mode
(`use_random_order=False`) the modifier reveals faces in their mesh-index
order. Python sorts that order before the modifier ever sees the mesh:

```python
bm.faces.sort(key=lambda f: f.calc_center_median().z)
bm.to_mesh(mesh)
```

The geode now grows strictly bottom-to-top without any random seed — fully
deterministic and reproducible.

## What blueprint.py builds

A faceted crystal geode column:

1. `bmesh.ops.create_icosphere(subdivisions=1)` → 80 triangular faces.
2. `bmesh.ops.poke(faces=all)` → each triangle becomes an outward spike pyramid.
3. `bm.faces.sort(key=z_center)` → Z-sorted index order for upward growth.
4. `_reveal_order` FACE INT attribute written (0 → N-1) for Three.js control.
5. `BuildModifier(frame_start=1, frame_duration=80, use_random_order=False)`.
6. Five depsgraph snapshots at frames 1, 20, 40, 60, 80 → `hf_crystal_stage_{0..4}.glb`.
7. Modifier removed; final-state GLB with `_reveal_order` → `hf_crystal_geode.glb`.

## Depsgraph snapshot pattern

```python
scene.frame_set(30)
dg  = bpy.context.evaluated_depsgraph_get()
ev  = ob.evaluated_get(dg)
snp = bpy.data.meshes.new_from_object(ev, depsgraph=dg)
```

`new_from_object(..., depsgraph=dg)` is the Blender 4.0+ context-free API.
It is safe in `--background` mode (no 3D Viewport needed) and captures the
fully evaluated geometry including all modifier stack output.


## Key API

```python
mod               = ob.modifiers.new("CrystalGrowth", 'BUILD')
mod.frame_start   = 1       # first face visible at this timeline frame
mod.frame_duration = 80     # frames to full reveal
mod.use_random_order = False # sequential = sorted index order
mod.use_reverse   = False   # True = demolish (reverse schedule)
mod.seed          = 42      # seed for Fisher-Yates shuffle (random mode only)
```
