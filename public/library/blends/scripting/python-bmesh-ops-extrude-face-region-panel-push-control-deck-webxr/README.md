# bmesh.ops.extrude_face_region — Panel-Push & Sci-Fi Control Deck

**Blender version:** 5.1

## What this is

A fully-scripted control deck prop built with `bmesh.ops.extrude_face_region`: the context-free kernel behind Blender's Extrude Region operator. The mesh demonstrates how to extrude grouped face selections to different heights — creating a raised display panel surround, left/right button banks, and top/bottom decorative strips — all from a single 8 × 6 quad grid.

## Key API points

1. `extrude_face_region` does **not** move geometry — always follow with `bmesh.ops.translate`.
2. `ret['geom']` is a flat mixed list; filter with `isinstance(g, bmesh.types.BMVert)`.
3. `use_keep_orig=True` duplicates the original faces (stamping pattern) rather than connecting them.
4. Contrast with `extrude_discrete_faces`: use that when each face must move in its own normal direction (per-button spikes); use `extrude_face_region` for single connected raised surfaces.

## Run it

Open Blender 5.1 → Scripting workspace → open `blueprint.py` → Run Script.

The script clears the default scene, builds the control deck, saves the .blend, and exports the GLB — all to the same directory.
