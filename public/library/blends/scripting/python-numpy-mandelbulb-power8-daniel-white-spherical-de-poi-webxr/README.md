## What this is

A WebXR poi-head mesh whose surface is the outer hull of the **Mandelbulb**
at exponent 8 — the canonical "White–Nylander" fractal discovered in 2009 when
Daniel White generalised Mandelbrot's z → z² + c to three dimensions using
spherical coordinates.

The blueprint samples the isosurface by marching 9,600 radial rays inward
from r = 1.45 and recording where Inigo Quilez's Distance Estimator (DE)
drops below 0.004. The DE gives a rigorous lower bound on the true distance
to the fractal boundary, so the scan is guaranteed not to tunnel through
surface features wider than DE_HIT at the chosen step resolution.

## How the distance estimator works

```
At each point c ∈ ℝ³, iterate:
    z_{n+1} = z_n^power + c   (spherical coordinate power rule)

Track the derivative magnitude:
    |dz'| = power · |z|^(power-1) · |dz| + 1

When |z| > 2.0 (escaped), the DE lower bound is:
    DE(c) = 0.5 · |z| · ln|z| / |dz|
```

Positive DE → outside the set.  Near-zero → on the boundary.  Negative
(interior sentinel) → inside, iteration did not escape.
