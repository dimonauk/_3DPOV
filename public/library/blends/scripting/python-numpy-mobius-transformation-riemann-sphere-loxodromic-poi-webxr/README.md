# Möbius Transformation Gallery — PSL(2,ℂ) Conformal Maps & Loxodromic Spirals

**Blender 5.1 · Python 3.11 · CC0**

A Möbius transformation is any map f(w) = (aw + b)/(cw + d) where a,b,c,d ∈ ℂ
and ad − bc ≠ 0.  The group of all such transformations is PSL(2,ℂ), and it acts
on the Riemann sphere ℂ∪{∞} — equivalently, via stereographic projection, on
the ordinary unit sphere S² in ℝ³.

Every non-identity element falls into exactly one conjugacy class, determined by
its trace-squared tr(M)²:

| Class | tr(M)² | Fixed points | Orbit shape |
|---|---|---|---|
| Elliptic | [0, 4) real | Two conj. pts on S² | Circles of latitude |
| Hyperbolic | (4, ∞) real | Two real pts | Intervals on a geodesic |
| Parabolic | 4 (exactly) | One tangent pt | Horocycles |
| **Loxodromic** | **ℂ \ [0, ∞)** | **Two real pts** | **Logarithmic spirals** |

The **loxodromic** case produces the richest geometry.  Choosing fixed points at
the poles (w = 0 and w = ∞ in stereographic coordinates) and defining the
one-parameter family f_t(w) = λ^t · w, where λ = exp(log_r + i·α), gives orbits
that simultaneously spiral and drift — exactly the path of a poi light on the
sphere of its reachable positions during a combined spin and lean.

## Algorithm at a Glance

```
Stereographic projection (north pole):
    w(x, y, z) = (x + iy) / (1 − z)     [S² \ {N} → ℂ]

Inverse:
    x = 2u/(|w|²+1),  y = 2v/(|w|²+1),  z = (|w|²−1)/(|w|²+1)

One-parameter loxodromic family (fixed pts: 0 and ∞):
    f_t(w) = λ^t · w,    λ = e^{LOG_R + i·ALPHA}
    |f_t(w)| = e^{LOG_R·t} · |w|     (radial drift)
    arg(f_t(w)) = ALPHA·t + arg(w)   (angular rotation)
```

Orbits starting at the equator (|w| = 1) trace logarithmic spirals on S²,
converging at the north pole as t → +∞.

## Parameters

| Constant | Value | Meaning |
|---|---|---|
| `LOG_R` | 0.55 | Re(log λ) — drift per unit t |
| `ALPHA` | π/5 = 36° | Im(log λ) — rotation per unit t |
| `N_ORBITS` | 72 | Spiral tubes (full spectral colour sweep) |
| `T_MIN / T_MAX` | −2.8 / +2.8 | Parameter range (clips at poles) |
| `T_STEPS` | 64 | Points per NURBS orbit |
| `BEVEL_DIM / THICK` | 0.0035 / 0.008 m | Regular vs guide-orbit tube radius |
