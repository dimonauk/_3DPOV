# Python bpy.types.BoneCollection — Rig Classification for VRM & WebXR

**Blender 5.1 · Python scripting · Armature organisation · VRM export prep**

## What this is

Blender 4.0 replaced the 32-layer armature system with named `BoneCollection`
objects. In Python, `arm.collections.new("name")` creates a collection and
`bone.collections.link(coll)` assigns any bone to it — the operation works on
`Bone` (object mode) and `EditBone` (edit mode) via their respective data
representations.

For VRM export, `bone.use_deform` decides which bones drive skinning. Collections
are organisational; the exporter reads `use_deform`, not collection membership.
Aligning collections with deform intent keeps the rig auditable.

## Key API facts

```python
# Create a collection
coll = arm_data.collections.new("DEF — Deform")
coll.is_visible = True

# Assign bones (OBJECT mode)
arm_data.bones["DEF-spine.001"].collections.link(coll)

# Set deform flag (controls VRM skinning export)
arm_data.bones["DEF-spine.001"].use_deform = True

# Colour a pose bone
arm_obj.pose.bones["DEF-spine.001"].color.palette = "THEME09"  # green

# Audit: iterate collection members
for bone in arm_data.collections["DEF — Deform"].bones:
    print(bone.name, bone.use_deform)

# Set active collection (sidebar highlight)
arm_data.collections.active_index = 0
```

## Pitfalls

- `arm.layers` still exists in 5.1 but maps to the first 20 collections.
  Mixing both APIs produces unpredictable UI state. Use only `arm.collections`
  in new scripts.
- `BoneCollection` has no colour property in the public Python API as of 5.1.
  The per-collection tinting in the UI is a C-level integer; colour bones via
  `pose_bone.color.palette` instead.
- `bone.collections.link()` on an `EditBone` requires EDIT mode to be active.
  On `arm_data.bones[name]` (object-mode representation) it works without mode
  switching, which is the headless-safe approach.
- Clearing all collections from a bone (every `unlink()`) does not delete the
  bone; it simply appears in no collection and is always visible when any
  collection is active.

## VRM classification convention

| Collection | Prefix | `use_deform` | Exported to skin? |
|-----------|--------|-------------|-------------------|
| DEF — Deform | `DEF-` | `True` | Yes |
| CTRL — Controls | `CTRL-` | `False` | No |
| MCH — Mechanism | `MCH-` | `False` | No |
| ROOT | `ROOT` | `False` | No |
