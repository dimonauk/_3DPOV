## What is a Lissajous knot?

A Lissajous knot is defined by the simplest possible formula for a space curve:

```
x(t) = cos(nₓ · t + φₓ)
y(t) = cos(n_y · t + φ_y)
z(t) = cos(n_z · t + φ_z)
```

Three cosine oscillators. Three integers. Three phases. The result — depending
on the frequency triple (nₓ, n_y, n_z) — is a trefoil, a figure-eight, a
cinquefoil, or something far more knotted. The name comes from Jules Antoine
Lissajous (1857), who drew the 2D projections on a screen using tuning forks.
The 3D version creates proper topological knots.

The connection to Chebyshev polynomials is exact: cos(n·arccos(u)) = T_n(u).
So evaluated at t = arccos(u), each coordinate becomes a Chebyshev polynomial
of u — meaning the knot is the image of a degree-(nₓ, n_y, n_z) polynomial
map. This is why Koseleff and Pecker (2011) call them "Chebyshev knots" and
prove that every knot type can be realised this way for large enough n.

---

## Key theorem: amphichirality

**Every Lissajous knot is amphichiral** (isotopic to its mirror image).

Proof sketch: the phase-reversal t → −t sends cos(n·t + φ) to cos(n·t − φ),
which reflects the knot across the φ = 0 hyperplane. In the ambient isotopy
this is precisely the mirror image. Since the reparametrisation t → −t is a
smooth diffeomorphism of the circle, the reflected knot is isotopic to the
original. ∎

Consequence: Lissajous knots have trivial Nakanishi index (all Seifert
forms are metabolic), vanishing Tristram-Levine signatures at all roots of
unity, and Arf invariant 0.

## Running the blueprint

1. Open Blender 5.1.
2. Open the **Scripting** workspace.
3. Click **Open** and navigate to `blueprint.py`.
4. Click **▶ Run Script**.
5. Check the System Console for the ✓ confirmation line.
6. The `.blend` and `.glb` are written relative to the script location.

**Dependencies:** NumPy — included in Blender 5.1's bundled Python.  
No pip install required.
