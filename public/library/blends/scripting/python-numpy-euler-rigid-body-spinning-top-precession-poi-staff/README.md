# Euler Rigid Body — Torque-Free Spinning Top Precession

**Blender 5.1 · Python · numpy · scripting**

A torque-free rigid body — a poi staff in free flight — obeys Euler's
equations for the angular velocity in the body-fixed frame, coupled with
quaternion kinematics that track the lab-frame orientation.  This blueprint
integrates both with a 480 Hz 4th-order Runge-Kutta loop, bakes 241
quaternion keyframes onto a poi staff cylinder, and deposits the body-frame
ω trace (the **polhode**) as an amber POLY curve for a light-painting prop.

## Physics background

- **Euler's equations** (body frame, torque-free): each ωᵢ couples to the product of the
  other two, modulated by the moment differences (Iⱼ−Iₖ).
- **Poinsot construction** (1834): the polhode is the intersection of the energy
  ellipsoid `½(I₁ω₁²+I₂ω₂²+I₃ω₃²)=T` and the angular momentum sphere
  `(I₁ω₁)²+(I₂ω₂)²+(I₃ω₃²)=L²`.
- **Intermediate-axis theorem**: rotation about the intermediate principal axis
  (I₁>I₂>I₃) is unstable. Any perturbation grows exponentially until the body
  has rotated 180° about the spin axis — the "tennis-racket flip" or "Dzhanibekov
  effect", observed in orbit aboard the ISS.
- **Quaternion integration**: using Euler angles instead would introduce gimbal lock
  at ±90° nutation; the quaternion formulation handles all orientations uniformly.
