# Screen Recording Notes — Barkley Spiral Wave Poi Head

## Goal

Capture `screen.mp4` showing the full workflow:
Script Editor → run `blueprint.py` → inspect the displaced spiral-wave sphere
in the 3D Viewport → toggle between shape keys → File ▸ Export GLB.

Target: **90–120 seconds**, 1920 × 1080, 30 fps.

## Shot list

### 1. Script Editor (0–25 s)
- Switch to **Scripting** workspace.
- Open `blueprint.py` via **Text ▸ Open**.
- Scroll slowly through the Barkley PDE equations block (`_du`, `_dv`) — pause
  so viewers can read the two-line reaction terms and the time-scale ratio `ε`.
- Continue scrolling past the `_rk2_step` function; pause briefly on the
  midpoint comment explaining *why* RK2 over Euler.
- Pause on the initial conditions block that creates the phase singularity.

### 2. Run script (25–50 s)
- Press **Alt+P** (or click ▶ Run Script).
- Whilst it runs, switch briefly to the **Timeline** panel to show the empty
  scene, then back to the Viewport when the object appears.

### 3. Viewport inspection (50–80 s)
- Switch to **3D Viewport** (Vertex-Colour shading via the drop-down, FLAT
  lighting).
- Orbit slowly: viewers should see the indigo-to-flame-yellow gradient
  following the spiral wavefront across the sphere surface.
- Open **Object Data Properties ▸ Shape Keys** in the Properties panel.
- Click through `Spiral_T2` and `Spiral_T3` keys (drag the Value slider
  0 → 1 slowly each time) — the spiral rotates visibly on the sphere.

### 4. Material shading (80–95 s)
- Switch renderer to **Eevee Next** and set shading to **Rendered**.
- Brief orbit to show the emission glow — wave crests are bright yellow-orange,
  the quiescent region is deep indigo-blue.

### 5. Export GLB (95–115 s)
- **File ▸ Export ▸ glTF 2.0**.
- Enable: Draco mesh compression (level 6), Include Vertex Colors, Include
  Shape Keys, Apply Transforms, Y Up.
- Export to `public/library/glbs/scripting/…/hf_barkley_spiral.glb`.
