# Hénon Map Strange Attractor

**Blender 5.1 | Python + numpy | CC0**

Two Blender objects from one 42-line iteration loop:

- **hf_henon_basin** — a 200 × 200 quad surface where Z encodes the escape-time fraction of the fractal basin boundary, vertex-coloured with a plasma hue ramp (purple = inside basin, yellow = fast escape).
- **hf_henon_trail** (×3) — NURBS bevel curves tracing the strange attractor orbit lifted into 3D poi arm-reach space.

## The map

```
x' = 1 − 1.4·x² + y
y' = 0.3·x
```

After 500 transient iterations from (0.1, 0.1) the orbit settles onto the attractor and stays there for billions of steps without repeating — deterministic chaos.

## Run

Open Blender 5.1 → Text Editor → Open → `blueprint.py` → Run Script.  
Produces `hf_henon.glb` alongside the script (~380 KB with Draco compression).

For the viewport recording animation, run `record.py` similarly.
