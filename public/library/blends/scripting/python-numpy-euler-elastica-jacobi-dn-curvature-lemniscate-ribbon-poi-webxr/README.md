## What this is

The Euler–Bernoulli elastica (1744) is the world's first recorded variational
problem on space curves.  Euler proved that curves minimising the integral of
squared curvature ∫κ²ds subject to fixed arc length satisfy the ODE

    κ'' + κ³/2 = T·κ

where T is a Lagrange multiplier (tension).  Substituting κ = a·dn(b·s, m)
into this ODE — using the Jacobi elliptic ODE dn'' = (2−m²)dn − 2dn³ — forces
the exact relations a = 2b and T = b²(2−m²).  This is the **non-inflectional
oval elastica**: curvature stays positive and the curve closes naturally.

The **exact closure modulus** m* ≈ 0.3476 satisfies E(m*)/K(m*) = (2−m*²)/2,
derived by integrating x(s) = ∫cos(2·am(ks, m))ds = 0 over one half-period.

**Lemniscate connection**: the arc length of the lemniscate r² = a²cos(2θ)
uses the same integrand dn(t, 1/√2) — the elastica at modulus 1/√2.
Bernoulli and Euler both computed this same integral, which is why "elliptic"
integrals carry the lemniscate's name.
