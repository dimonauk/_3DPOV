# SkinModifier — Wire to Mesh via BMesh Skin Vertex Layer

**Blender 5.1 · holoflow_webxr_exporter · CC0**

Converts a mesh of vertices and edges (no faces) into a closed skin surface.
Per-vertex X/Y radii are stored in a custom BMesh layer. Stacking
`SubsurfModifier` at `levels=1` rounds junction artefacts without losing the
faceted blockout character.

## Key insight

The `SkinModifier` reads geometry from the BMesh skin vertex layer, not from
vertex weights or UV coordinates. The layer is written during mesh construction:

```python
bm = bmesh.new()
v_a = bm.verts.new((0, 0, 0))
v_b = bm.verts.new((0, 0, 1))
bm.edges.new((v_a, v_b))

sl = bm.verts.layers.skin.verify()   # creates or retrieves the layer
v_a[sl].radius   = (0.15, 0.15)
v_a[sl].use_root = True              # suppress open end-cap at this vertex
v_b[sl].radius   = (0.08, 0.08)

bm.to_mesh(mesh)
bm.free()

obj.modifiers.new("Skin", "SKIN")
```

At least one vertex per connected component must be marked `use_root=True`.
Without it, `SkinModifier` opens end-caps at both extremities and WebXR
back-face culling reveals the interior.

## Gotchas

- `bm.verts.layers.skin.verify()` must be called **before** `bm.to_mesh()` —
  the skin layer lives in the BMesh; writing to the mesh first drops it.
- Radii are in **local space** before object scale is applied. Applying a 2×
  scale doubles world-space tube diameters but leaves radius values unchanged.
  Apply transforms (`bpy.ops.object.transform_apply(scale=True)`) before export.
- `branch_smoothing=1.0` over-inflates shoulder junctions on bifurcating
  topology — keep it at `0.4` or below to avoid balloon artefacts at the chest.
- `use_x_mirror=True` mirrors skin-vertex data in Edit Mode interactively.
  In headless Python, define both sides explicitly — the flag has no effect
  on the generated surface outside of interactive editing.
