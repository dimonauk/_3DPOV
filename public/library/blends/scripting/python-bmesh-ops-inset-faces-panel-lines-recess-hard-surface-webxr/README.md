# bmesh.ops.inset_faces — Panel-Line Grooves & Recessed Faces

**Blender 5.1 · Python scripting · Hard-surface prop · WebXR GLB**

`bmesh.ops.inset_faces` is the context-free kernel behind Blender's
**Inset Faces** operator (I key). Unlike the interactive operator it
takes an explicit list of `BMFace` objects and returns the resulting
inner faces — no 3D Viewport, no active selection, no undo stack.

## What this blueprint builds

A single console-panel prop (`hf_inset_panel.glb`) demonstrating three
distinct inset strategies on one mesh:

| Zone | Technique | Parameters |
|------|-----------|------------|
| A — Panel-line border | Collective inset (`use_individual=False`) | `thickness=0.025`, `depth=-0.006` |
| B — Button cluster | Individual inset (`use_individual=True`) | `thickness=0.030`, `depth=-0.018` |
| C — Vent grille | Alternating-face collective inset | `thickness=0.010`, `depth=-0.004` |

## Key concepts

- **`use_individual`** is the single most important boolean: `False` traces
  one groove ring around the entire face selection; `True` gives every face
  its own isolated ring.
- **`depth`** displaces the inner face along its normal — negative values push
  it into the mesh (recess); positive values raise it (boss/stud).
- **`use_even_offset`** compensates for non-square faces so the groove width
  stays consistent across differently shaped quads.
- **`result['faces']`** contains the inner faces after inset — chain further
  bmesh ops (extrude, assign material index) to them directly.

## Running

```bash
blender --background --python blueprint.py
```

Or open `hf_inset_panel.blend` in Blender 5.1 and paste `blueprint.py`
into the Scripting workspace.
