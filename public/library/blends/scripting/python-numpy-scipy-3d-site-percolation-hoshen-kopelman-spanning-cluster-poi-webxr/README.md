# 3D Site Percolation — Hoshen–Kopelman Spanning Cluster & Poi Head

**Topic:** scripting · **Blender:** 5.1 · **Licence:** CC0

At the critical threshold p_c ≈ 0.3116 of site percolation on a simple
cubic lattice, the largest connected cluster of occupied sites is a
**fractal with Hausdorff dimension ≈ 2.52**.  Below p_c there are only
finite isolated blobs; above p_c a dense sphere-like mass dominates.
Right at the boundary, the maximum visual complexity is achieved.

This entry generates the spanning cluster on a 55³ lattice at p = p_c,
constructs an exposed-face voxel mesh, colours it by height (amber →
teal), and exports a faceted poi head for WebXR.

## Critical exponents (3D universality class)

| Exponent | Value | Meaning |
|---|---|---|
| ν | 0.876 | Correlation length ξ ~ |p − p_c|^{−ν} |
| β | 0.418 | Infinite cluster density P_∞ ~ (p − p_c)^β |
| γ | 1.793 | Mean cluster size S ~ |p − p_c|^{−γ} |
| d_f | 2.524 | Fractal dimension of spanning cluster at p_c |
