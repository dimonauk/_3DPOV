# Screen-Recording Notes — ABC Flow Poi Light Brush

Follow these steps to record **screen.mp4** — the companion human-visible
recording that accompanies `viewport.mp4` (generated by `record.py`).

---

## Software

- **OBS Studio 30+** (Windows / macOS / Linux) — free, open source.
- Or **NVIDIA ShadowPlay / Xbox Game Bar** on Windows.
- Blender **5.1**.

---

## Setup

1. Open Blender 5.1.  
2. Switch to the **Scripting** workspace.  
3. Open `blueprint.py` in the text editor (or paste it).  
4. Press **Run Script** (▶) — expect ~30–60 s for 54 × 3 000 RK4 steps.  
5. Switch to the **Layout** workspace once the mesh appears.

---

## Viewport display

| Setting | Value |
|---------|-------|
| Viewport shading | **Rendered** (EEVEE Next) |
| Overlay: wireframe | **Off** |
| Overlay: grid | **Off** |
| Viewport: bloom | should be on (set in script) |
| Background | **Black** (World shader sets this) |

Rotate the view so all three colour bundles (cyan, magenta, gold) are visible.

---

## OBS configuration

| Parameter | Value |
|-----------|-------|
| Source | **Window Capture → Blender** |
| Resolution | **1920 × 1080** |
| Frame rate | **30 fps** |
| Audio | **Off** |
| Encoder | x264 or NVENC H.264 |
| Output | `screen.mp4` |
| Bitrate | 8 Mbps |

---

## What to record

1. **0 – 5 s**: orbit the viewport slowly — use numpad 4/6 to rotate — showing
   the full entangled mesh from three angles.
2. **5 – 10 s**: zoom into one colour group so the individual tube bevel is
   visible.
3. **10 – 15 s**: pull back to full view; use numpad 0 to enter camera view
   and show the viewport.mp4 camera angle.
4. **15 – 20 s**: orbit once more, then stop.

Target duration: **≤ 20 seconds**.
