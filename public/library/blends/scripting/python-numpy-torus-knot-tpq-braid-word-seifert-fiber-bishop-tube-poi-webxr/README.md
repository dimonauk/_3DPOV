## What this is

A torus knot K = T(p,q) with gcd(p,q) = 1 winds around the standard torus T² ⊂ ℝ³
exactly p times around the central (z) axis and q times around the tube axis.
It is the simplest infinite family of non-trivial knots: T(2,3) is the trefoil,
T(2,5) the cinquefoil (5₁), T(3,4) and T(3,5) the algebraic knots 8₁₉ and 10₁₂₄.

This entry builds a closed tube along the knot centreline using a **Bishop
parallel-transport frame** — Robert Bishop's 1975 fix for the Frenet frame's
failure at inflection points.  The frame is bootstrapped from an arbitrary seed
normal, transported step-by-step via Rodrigues' rotation formula, and then
corrected by distributing the end-closure torsion deficit linearly across all
frames.  The result is a smooth, twist-free tube with no normal-vector singularities.

Four knot types are stored as **shape keys** (morph targets) so the poi head can
animate between them in a WebXR scene or a GLB viewer:

| Shape key | Knot | Genus | Signature |
|-----------|------|-------|-----------|
| `Trefoil_T23` | T(2,3) | 1 | −2 |
| `Solomon_T25` | T(2,5) | 2 | −4 |
| `Torus_T34`   | T(3,4) | 3 | −6 |
| `Torus_T35`   | T(3,5) | 4 | −8 |

Vertex colours are keyed to the arc-length parameter t ∈ [0,2π) and cycle through
a warm-to-cool HSV gradient, giving the tube a rainbow light-trail appearance
that reads well as a poi prop.

## Mathematical background

The parametrisation is:

```
c(t) = ( (R + r cos qt) cos pt,
          (R + r cos qt) sin pt,
                 r sin qt ),   t ∈ [0, 2π)
```

with R = 1.0 (major radius), r = 0.42 (minor radius), and endpoint=False so
the curve closes exactly without a duplicated point.

Key invariants:
- **Genus** g(T(p,q)) = (p−1)(q−1)/2 — the minimum genus of any Seifert surface
  bounded by K, proved by Seifert's algorithm (1934).
- **Signature** σ(T(p,q)) = −(p−1)(q−1) — the number of negative eigenvalues
  minus positive in the symmetrised Seifert matrix.
- **Braid word** — T(p,q) = closure of (σ₁σ₂…σ_{p-1})^q in the p-braid group Bₚ.
  The braid has pq positive crossings and braid index p (or q, whichever is smaller).
- **Alexander polynomial** — Δ_{p,q}(t) = (t^{pq}−1)(t−1) / ((t^p−1)(t^q−1)).
  This is a genuine polynomial in t (the apparent fractions cancel).
- **Self-linking** — lk(K, K_Seifert) = pq, where K_Seifert is the push-off
  in the direction of the Seifert framing.

## Running the script

1. Open Blender 5.1.
2. Switch to the **Scripting** workspace.
3. Open `blueprint.py` in the text editor panel.
4. Press **Run Script** (▶ button or Alt+P).

The script clears the scene, builds the T(2,3) trefoil base mesh, adds all four
shape keys, applies the emission material, and exports the GLB.
Expected runtime: ~3–8 seconds depending on hardware.

## Blender 5.1 notes

- `me.attributes.new("Col", "FLOAT_COLOR", "POINT")` — `FLOAT_COLOR` is the
  correct domain constant for per-vertex colour in Blender 5.x (replaces the
  legacy `MLoopCol` attribute path from 3.x).
- `export_apply=False` in the GLTF exporter — essential when shape keys are
  present; `True` would bake all modifiers and discard the morph targets.
- `mat.shadow_method = "NONE"` suppresses shadow computation for the emissive
  tube, which is correct for a light-trail prop.
