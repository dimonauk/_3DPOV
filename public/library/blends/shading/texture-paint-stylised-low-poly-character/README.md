# Texture Painting: Hand-Painted Stylised PBR on a Low-Poly Gem Totem

**Blender 5.1 · CC0**

---

## What This Is

A production blueprint for creating hand-painted PBR texture atlases on low-poly stylised characters in Blender 5.1. The subject is a faceted icosahedron totem with four distinct material zones — stone base, gunmetal panels, warm ochre skin facets, and a glowing cyan gem crown.

Rather than using `bpy.ops.texture_paint` (which requires a live GPU context and fails in headless batch rendering), the blueprint uses **numpy UV-triangle rasterisation** to fill each face's UV island with zone-based colour. This approach is fully reproducible in CI pipelines, headless batch runs, and interactive sessions alike.

## How to Run

```
blender --background --python blueprint.py
```

Or open Blender 5.1, open the Text Editor workspace, load `blueprint.py`, click Run Script.

---

## Key Techniques

- **Smart UV Project** (`bpy.ops.uv.smart_project`) with `angle_limit=66°` and `island_margin=0.02` for a clean, non-overlapping atlas.
- **UV Triangle Rasterisation** — barycentric coordinate testing over each icosahedron triangle in UV space; fills numpy pixel arrays deterministically.
- **Single Unified Material** — all four visual zones share one Principled BSDF driven by three image textures. Reduces WebXR draw calls.
- **Emission from Image Texture** — the emit map feeds both Emission Color and Emission Strength, letting the gem crown glow at 3.2× without over-brightening neighbouring zones.
