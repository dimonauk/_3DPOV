# Shader — Procedural Lava / Magma Flow Material

**Blender version:** 5.1  
**Topic:** Shading  
**Licence:** CC0  
**Tutorial:** [/tutorials/blender-tutorial-shader-procedural-lava-magma-flow](/tutorials/blender-tutorial-shader-procedural-lava-magma-flow)

## What This Builds

A fully procedural lava surface with animated crack emission, displaced plate topology,
and EEVEE Next bloom halation.  No image textures — entirely node-driven using two
Voronoi lookups operating on the same animated UV stream.

## Files

| File | Purpose |
|------|---------|
| `blueprint.py` | Full bpy script — creates material, mesh, camera, exports .blend + .glb |
| `record.py` | Renders 120-frame viewport animation to `videos/…/viewport.mp4` |
| `SCREEN-RECORDING-NOTES.md` | OBS instructions for `screen.mp4` |
| `lava_magma_flow.blend` | Blender project (generated by blueprint.py) |
| `lava_magma_flow.glb` | WebXR-ready GLB with emissive cracks via KHR_materials_emissive_strength |

## Key Technique

```
Generated UV → Mapping (Y-driver: frame×0.003)
  ├─ Voronoi DISTANCE_TO_EDGE → Invert → Crack Ramp → Emission (strength 6.0)
  ├─ Voronoi F1              → Plate Colour Ramp → Principled BSDF
  ├─ Mix Shader (crack_mask as Fac)
  └─ Voronoi F1 → Invert → Displacement (scale 0.12 m)
```

## Running

```bash
blender --background --python blueprint.py
# then, with the generated blend open:
blender lava_magma_flow.blend --python record.py
```
