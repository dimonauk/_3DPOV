# Shader — Subsurface Scattering: Stylised Skin

**Blender 5.1 · Category: shading · Licence: CC0**

Principled BSDF v2 multi-region SSS for anime/VRM characters.
Covers face skin, ear translucency glow (pinna cartilage), and lip flush.
Random Walk Skin method for accurate thin-geometry behaviour.

## Files

| File | Purpose |

| `blueprint.py` | Full bpy scene + material build script |
| `record.py` | Viewport animation render (360° rotation, rim pulse) |

## Key technique

Subsurface Radius `(R, G, B)` encodes biological light penetration depth:

- **Red (700 nm)** — longest MFP in skin (~60 mm effective at Scale 0.06)
  because haemoglobin absorbs at blue/green but passes red
- **Green (550 nm)** — mid-range (~25 mm effective)
- **Blue (450 nm)** — shortest (~15 mm effective), absorbed by melanin + Hb

Ears use `EAR_SSS_WT = 0.90` (vs face `0.55`) because the pinna is
typically 1–3 mm thick — photons escape quickly and the transmitted
colour is dominated by the blood-layer red shift.

## Running

```bash
blender --background --python blueprint.py
blender --background sss_skin.blend --python record.py
```
