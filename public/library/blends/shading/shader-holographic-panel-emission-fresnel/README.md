# Holographic Interface Panel — Emission + Fresnel + Voronoi + Wave

**Blender 5.1 · EEVEE-Next · Shader tutorial · Licence: CC0**

A fully procedural holographic panel shader combining three signal layers
over a near-invisible transparent base. All pattern parameters are tunable
constants at the top of `blueprint.py`; no external textures required.

## Technique summary

| Layer | Node | Role |
|---|---|---|
| Hex grid | Voronoi (DISTANCE_TO_EDGE, 2D) | Cell boundary lines |
| Scan lines | Wave Texture (BANDS, Y direction) | Scrolling horizontal data stripes |
| Edge glow | Fresnel (IOR 1.42) | Silhouette rim amplification |
| Alpha | Sum of above signals | Near-invisible face-on, solid at lines and rim |

The Fresnel multiplier `(1 + FRESNEL_EMIT_BOOST × fresnel)` amplifies both
the emission strength and the alpha at the panel's silhouette edge, producing
the characteristic holographic "rim-brighter-than-face" read.

## Files

| File | Purpose |
|---|---|
| `blueprint.py` | Full bpy scene: panel geometry + shader + camera + render settings |
| `record.py` | Renders 150-frame camera-orbit clip to `videos/…/viewport.mp4` |
| `SCREEN-RECORDING-NOTES.md` | OBS setup for `screen.mp4` (human-in-Blender recording) |
| `holographic_panel.blend` | Generated by blueprint.py (not committed) |
| `holographic_panel.glb` | Generated by blueprint.py (not committed) |

## Running

```bash
# Generate .blend and .glb
blender --background --python blueprint.py

# Render the viewport clip
blender holographic_panel.blend --python record.py
```

## EEVEE-Next transparency notes

In Blender 5.1, `mat.surface_render_method = 'FORWARD'` is required for
sorted alpha transparency (replaces the 3.x `blend_method = 'BLEND'`).
Bloom must be enabled in Render Properties → Effects → Bloom for the
`Emission Strength > 1.0` halo to appear. Without Bloom the emissive scan
lines read as flat colour — technically correct but visually unconvincing.

## WebXR / GLB export

`KHR_materials_emissive_strength` is auto-applied when Emission Strength > 1.0.
In Three.js this maps to `MeshPhysicalMaterial.emissiveIntensity`, enabling the
same above-1.0 glow in the Atelier spatial viewer and model-viewer embeds.

Alpha transparency is exported via KHR's base glTF alpha mode `BLEND` — the
exporter reads `surface_render_method` and writes `alphaMode: "BLEND"` in the
material JSON. Panel backface-culling is disabled so both sides render in orbit.
