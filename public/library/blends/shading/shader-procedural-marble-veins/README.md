# Procedural Marble — Vein System

Blender 5.1 · Shading · CC0

A fully procedural marble shader — no image textures, no UV painting.
The vein network uses a Wave Texture with CONSTANT ColorRamp interpolation
for hairline-sharp edges.  Subsurface scattering gives the amber edge glow
characteristic of calcite, and the two-layer Clearcoat models polished stone.

## Parameters to experiment with

| Parameter | Default | Effect |
|-----------|---------|--------|
| `VEIN_DISTORT` | 2.5 | 0=straight ruled lines, 4=chaotic folds |
| `VEIN_STOP_HI` | 0.42 | Move closer to 0.35 for hairline veins |
| `VEIN_Z_COMPRESS` | 0.45 | 1=round blobs, 0.1=horizontal sweeping bands |
| `VEIN_COLOR` | near-black | Change to gold for Portoro, red for Rosso Levanto |
| `SSS_RADIUS` | (0.05,0.04,0.03) | Increase for alabaster/onyx translucency |
| `COAT_ROUGH` | 0.04 | Increase to 0.35 for honed/satin finish |
