# GN Duplicate Elements — Edge Domain Fins: Geometric Spike Shell

**Blender 5.1 | Geometry Nodes | CC0 | Holoflow Studio**

Produces a low-poly spike sphere: a UV sphere (14 segments × 10 rings) with one
fin quad extruded from every edge, creating a sea-urchin silhouette. Fins are
separate geometry from the body, assigned a contrasting material, and exported
as a single Draco-compressed GLB for WebXR.

## Technique summary

| Step | Node | Why |
|------|------|-----|
| 1 | `Normal` + `FieldOnDomain(Face→Edge)` | Converts face normals to edge domain before any duplication |
| 2 | `StoreNamedAttribute("fin_dir", Edge)` | Stamps the edge-domain normal onto the mesh so it survives duplication |
| 3 | `DuplicateElements(Edge, Amount=1)` | Clones every edge as a disconnected 2-vertex segment |
| 4 | `NamedAttribute("fin_dir")` | Reads the pre-stored direction from the copied edges |
| 5 | `NoiseTexture → remap → Multiply` | Varies fin height spatially (NOISE\_MIN × FIN\_HEIGHT … NOISE\_MAX × FIN\_HEIGHT) |
| 6 | `VectorMath SCALE` | Combines direction + magnitude into a single offset vector |
| 7 | `ExtrudeMesh(Edges)` | Sweeps each floating edge segment into a fin quad |
| 8 | `SetMaterial` + `JoinGeometry` | Assigns Fin material; rejoins fins with the untouched body |

## Key insight

`Duplicate Elements` (Edge domain) creates **face-free** copies of edges.
The `Normal` node would return zero on such a mesh because normals live on
faces. The solution is to evaluate and store the face normal as a named
attribute *before* duplicating — the attribute survives the copy while the
faces do not.

## Parameters

| Name | Default | Range | Effect |
|------|---------|-------|--------|
| Fin Height | 0.30 BU | 0 – 2 | Base extrusion length |
| Noise Scale | 2.5 | 0.1 – 20 | Spatial frequency of fin-height variation |
