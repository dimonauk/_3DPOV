# GN Sample Curve — Arc-Length Equidistant Track Sleepers

**Blender 5.1 · CC0 · Holoflow Studio**

Demonstrates `GeometryNodeSampleCurve` in **Length mode** to place ~38 railway
sleepers at physically equidistant arc-length positions around a Bezier oval, using
the Blender 5.x **Rotation socket type** for zero-workaround orientation.

## Key nodes

```
ObjectInfo (track_oval_curve)
    ↓ Geometry
MeshLine (count=40, offset=(0,0,0))          ← N point pool at origin
    ↓ Geometry
SetPosition (Position = SampleCurve.Position) ← move to curve
    ↓ Geometry
DeleteGeometry (Selection = SampleCurve.Is Valid)  ← cull out-of-range
    ↓ Geometry
InstanceOnPoints
  Instance  = MeshCube (2.4 × 0.14 × 0.22 m)
  Rotation  = SampleCurve.Rotation            ← Rotation socket (quat)
    ↓ Instances
SetMaterial → RealizeInstances → GroupOutput
```

## Why Sample Curve, not Resample Curve?

`Resample Curve(count=38)` distributes 38 points evenly in *parameter* space.
On a non-uniform curve (oval: tighter at the short-axis bends), parameter-space
sampling clusters points into tight bends and thins them on straight sections —
physical sleeper spacing becomes non-uniform.

`Sample Curve(mode=LENGTH)` samples at equal *arc-length* distances.
Each sleeper is exactly `SLEEPER_SPACING` metres from the next regardless of
local curvature. Real track geometry requirement: satisfied.

## Rotation socket (Blender 5.x)

Before Blender 4.0, `InstanceOnPoints.Rotation` accepted only an **Euler vector**
(XYZ angles in radians). Getting tangent orientation required an
`Align Euler to Vector` node wired to the `Tangent` output of `SampleCurve`.

From Blender 4.0+, `SampleCurve` returns a `Rotation` socket (quaternion
internally) and `InstanceOnPoints.Rotation` accepts it directly.
The old Euler workaround still works but is unnecessary.
