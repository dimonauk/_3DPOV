# GN Menu Switch — Tile Variant Kit

**Blender 5.1 · Geometry Nodes · Licence: CC0**

Builds a 1 × 1 m modular floor tile with four geometry variants
controlled by a labelled dropdown in the GN modifier stack.
`GeometryNodeMenuSwitch` + `NodeSocketMenu` group-input socket is the
canonical Blender 4.1+/5.x pattern for user-facing variant pickers.

## Variants

| # | Name    | GN technique                                              |
|---|---------|-----------------------------------------------------------|
| 0 | Flat    | Grid + Bevel Mesh (perimeter chamfer)                     |
| 1 | Raised  | 4×4-vertex grid, centre face selected by Index, Extruded  |
| 2 | Diamond | Grid rotated 45° + Bevel Mesh                             |
| 3 | Grate   | Grid slab extruded down, Boolean DIFFERENCE 3×3 cylinders |

## Usage

Open Blender 5.1 → Scripting workspace → Open `blueprint.py` → Run Script.

Then: select `tile_variant_kit` → Properties → Modifier (wrench) →
**Tile Variant** dropdown cycles Flat / Raised / Diamond / Grate.

Alternatively from the Python console:

```python
mod = bpy.data.objects['tile_variant_kit'].modifiers['TileVariantKit']
mod['Tile Variant'] = 2   # Diamond
```
