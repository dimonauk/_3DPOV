# GN Simulation Zone — Grey-Scott Reaction-Diffusion: Turing Pattern Emergence

**Blender 5.1 · CC0 · Holoflow Studio**

## What This Demonstrates

How to implement a full two-species partial-differential-equation (PDE) system
inside Blender's Geometry Nodes Simulation Zone.  The Grey-Scott (1983) model
produces Turing patterns — the same mathematics behind biological pattern
formation (leopard spots, zebra stripes, coral branching).

## Files

| File | Purpose |
|---|---|
| `blueprint.py` | Full `bpy` script — creates mesh, GN modifier, simulation, material |
| `record.py` | Automated viewport render to `viewport.mp4` |
| `SCREEN-RECORDING-NOTES.md` | OBS instructions for `screen.mp4` |
| `reaction_diffusion.blend` | Generated by `blueprint.py` |
| `reaction_diffusion.glb` | GLB snapshot at frame 180 (stable pattern) |

## How to Run

```bash
blender --background --python blueprint.py
blender reaction_diffusion.blend --background --python record.py
```

Or open `reaction_diffusion.blend`, press Space in the 3D viewport,
and watch the pattern grow from frame 1.

## Parameter Guide

| Parameter | Default | Effect |
|---|---|---|
| `Du` | 0.20 | Diffusion of U (substrate). Higher = smoother, larger features. |
| `Dv` | 0.10 | Diffusion of V (product). Lower relative to Du = finer textures. |
| `Feed` | 0.037 | Replenishment rate of U. |
| `Kill` | 0.060 | **The most interesting dial.** |

**Kill values and Pearson pattern types:**

| Kill | Pattern type |
|---|---|
| 0.056 | Moving solitons |
| 0.060 | Labyrinth / coral (default) |
| 0.062 | Isolated spots |
| 0.065 | Disappearing spots |

## GLB Export Notes

The GLB snapshot at frame 180 includes `conc_u` and `conc_v` custom accessors
(`export_attributes=True`).  Three.js reads these as `BufferAttribute`s on the
mesh geometry — useful for driving a custom shader.  The vertex colour pattern
can also be baked to a texture atlas for `KHR_materials_unlit` via Cycles bake
before the GLB export step.
