# GN Sample UV Surface — UV-Addressed Rivet Grid

**Blender:** 5.1  
**Topic:** Geometry Nodes — surface sampling  
**Slug:** `gn-sample-uv-surface-rivet-grid`  
**Licence:** CC0

## What This Is

A 6 × 6 grid of rivet cylinders placed on a noise-warped hull panel using
`GeometryNodeSampleUVSurface`.  The rivets are authored in UV space — each
rivet is a `(u, v)` coordinate — and the node maps those coordinates to 3D
surface positions and normals at runtime.

Because the placement is keyed to the UV map rather than vertex indices, the
rivets survive any topology change: adding a Subdivision Surface modifier,
deforming the hull with an armature, or running another GN modifier upstream
all leave the rivets correctly seated on the surface.

## Key Concepts

- **Inverse UV lookup** — (u,v) → 3D position + normal rather than the usual
  3D vertex → UV direction.
- **Is Valid guard** — rivets in dead UV space (gutters between islands) are
  deleted automatically via the `Is Valid` boolean output.
- **Two Sample UV Surface passes** — one for Position (`FLOAT_VECTOR`), one
  for Normal (`FLOAT_VECTOR`).  Both read from the *same* warped hull geometry
  so they are always consistent.
- **AlignEulerToVector (axis=Z)** — converts the sampled normal vector into a
  rotation Euler for `Instance on Points`, keeping each rivet head perpendicular
  to the local surface.

## Parameters (top of blueprint.py)

| Constant | Default | Effect |
|---|---|---|
| `RIVET_COLS` | 6 | Columns of rivets (U direction) |
| `RIVET_ROWS` | 6 | Rows of rivets (V direction) |
| `UV_MARGIN` | 0.12 | Keeps rivets off UV border seams |
| `NOISE_STRENGTH` | 0.14 m | Peak hull warp displacement |
| `RIVET_R` | 0.020 m | Rivet cylinder radius |
| `RIVET_H` | 0.024 m | Rivet cylinder height |

## Running

```bash
blender --background --python blueprint.py
```

Outputs: `rivet_hull.blend`, `rivet_hull.glb` in the same directory.

```bash
blender --background --python record.py
```

Outputs: `../../videos/geometry-nodes/gn-sample-uv-surface-rivet-grid/viewport.mp4`
