# GN Distribute Points in Volume — Crystalline Geode Interior

**Blender 5.1 · Geometry Nodes · CC0**

`GeometryNodeDistributePointsInVolume` scatters points inside a VDB fog volume
using density-weighted rejection sampling. This tutorial converts a
noise-displaced icosphere shell into a solid fog volume via
`GeometryNodeMeshToVolume`, scatters hexagonal bipyramid crystals throughout
the interior, filters out instances too close to the inner wall with
`GeometryNodeProximity`, and exports the shell + realised crystals as a
multi-material WebXR GLB.

## Files

| File | Purpose |

| `blueprint.py` | Full bpy script: shell, crystal prototype, GN tree, GLB export |
| `record.py` | EEVEE 360° orbit render → `videos/geometry-nodes/…/viewport.mp4` |

## Key Parameters

| Constant | Default | Effect |
|---|---|---|
| `VOXEL_SIZE` | 0.065 m | MeshToVolume resolution — smaller = more voxels, sharper interior |
| `VOL_INTERIOR_BAND` | 8.0 m | Fill depth; value ≫ radius fills the entire interior |
| `VOL_DENSITY_FACTOR` | 4.5 | Points-per-unit-volume multiplier |
| `MIN_CRYSTAL_DEPTH` | 0.20 m | Safety margin from inner surface — prevents clipping |
| `SCALE_MIN / SCALE_MAX` | 0.06 / 0.20 m | Per-instance crystal size range |

## How to Run

```bash
blender --background --python blueprint.py
blender --background crystal_geode.blend --python record.py
```

## Volume Domain Isolation

A Volume geometry has **no point, edge, or face domain**. Field nodes that read
mesh topology (Named Attribute, Edge Vertices, Input Normal) silently evaluate
to zero in a volume context. The correct pipeline is:

```
Mesh → MeshToVolume (Volume) → DistributePointsInVolume (PointCloud)
```

Only after DistributePointsInVolume (or VolumeToMesh) is the geometry back in
a domain where per-element fields can be evaluated.

## DENSITY_RANDOM vs DENSITY_GRID

| Mode | Scatter pattern | Use case |
|---|---|---|
| `DENSITY_RANDOM` | Organic, irregular | Natural formations, cave crystals |
| `DENSITY_GRID` | Perfect voxel lattice | 3-D-print infill, LED arrays |
