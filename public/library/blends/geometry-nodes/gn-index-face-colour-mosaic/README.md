# GN Index-Driven Per-Face Colour — Procedural Mosaic Tile

**Blender 5.1 · Geometry Nodes · CC0**

Builds a 16×16 quad grid whose faces are coloured by their flat index.
`GeometryNodeInputIndex` evaluates once per face; `Math(MODULO)` extracts
the column bucket; `Math(DIVIDE)` normalises to a hue float 0–1;
`ShaderNodeCombineColor(HSV)` converts to RGB; `StoreNamedAttribute` writes
`tile_colour` at FACE domain. An Emission material reads it via
`ShaderNodeAttribute` — no UV, no texture, no bake step needed.

## Key concept — FACE domain vs VERTEX domain

| Domain | Stored at | Interpolated across face? | Visual result |
|---|---|---|---|
| VERTEX | per vertex | yes | smooth gradient |
| FACE | per face | no | hard-edge constant tile colour |

Use FACE domain when you want zero colour bleed at edges — essential for
pixel-art / mosaic aesthetics and for hard-surface panel colouring.
