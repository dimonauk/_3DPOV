# GN Simulation Zone — Spring-Pendulum Poi Tether
## Elastic Orbit with Air Drag & Lissajous Path for Light-Painting Viewport
**Blender 5.1 · Geometry Nodes · CC0 · Holoflow Studio**

---

## What this does

A poi head hangs from an elastic tether whose upper end (the "hand") moves in
a prescribed circular orbit.  The GN Simulation Zone integrates Newton's
second law frame-by-frame using the semi-implicit Euler method, accumulating
the poi head's trajectory as a coloured ribbon.

When the hand orbit frequency ω_h sits near a rational multiple of the tether's
natural frequency ω₀ = √(k/m), the resulting trace is a Lissajous curve —
the same family of shapes that poi spinners call the butterfly, the petal weave,
and the isolation.  This tutorial formalises that connection in physics and
shows how to implement it inside a Blender 5.1 Simulation Zone.

## Physics summary

```
d       = r_poi − r_hand           displacement along tether
stretch = |d| − L₀                 extension beyond natural length
F_spring = −k · stretch · d̂        restoring force
F_drag   = −c · v                  linear air resistance

Semi-implicit Euler (symplectic; energy-stable at larger dt than explicit):
  v_{n+1} = v_n + (F_spring + F_drag) / m · Δt
  r_{n+1} = r_n + v_{n+1} · Δt
```

Default parameters (all at top of blueprint.py):

| Symbol | Value | Meaning |
|---|---|---|
| k | 90 N/m | spring stiffness |
| m | 0.05 kg | poi head mass |
| c | 0.8 N·s/m | drag |
| L₀ | 0.60 m | natural tether length |
| R_h | 0.25 m | hand orbit radius |
| ω_h | 7.0 rad/s | hand orbit angular velocity |
| ω₀ | ≈42 rad/s | tether natural frequency |

## How to run

```sh
blender --background --python blueprint.py
```

The script creates the scene, runs the physics, builds ribbon curves,
and exports `hf_poi_lissajous.glb` to the same directory.
