# GN Dual Mesh — Procedural Voronoi Cell Sphere (Blender 5.1)

The **Dual Mesh** node converts an ico sphere's triangulated topology into its
topological dual: each triangle face becomes a vertex, each vertex becomes a
polygon.  The result is the spherical Voronoi tessellation of the original
vertex set.  Perturbing the vertices with a noise texture *before* dualising
makes the cells organic without any additional randomisation node.

## Files

| File | Description |
|------|-------------|
| `blueprint.py` | Full bpy scene construction script |
| `record.py` | Automated orbit render → `viewport.mp4` |
| `SCREEN-RECORDING-NOTES.md` | OBS instructions for manual screen recording |
| `voronoi_cell_sphere.blend` | Generated by `blueprint.py` |
| `voronoi_cell_sphere.glb` | GLB export (Draco 6, WebP) |

## Running

```bash
# Build the .blend and .glb
blender --background --python blueprint.py

# Render the viewport animation
blender voronoi_cell_sphere.blend --background --python record.py
```

## Key parameters (top of `blueprint.py`)

| Constant | Default | Effect |
|----------|---------|--------|
| `ICO_SUBDIVISIONS` | 3 | Triangle count (3 → 1280 → 642 cells) |
| `NOISE_STRENGTH` | 0.08 | Cell irregularity (0 = geodesic dome) |
| `CELL_SCALE` | 0.87 | Inter-cell gap (lower = wider gap) |
| `EXTRUSION_DEPTH` | 0.055 | Tile height |

## Topology note

An ico sphere at subdivision level N has:
- Faces: 20 × 4^N
- Vertices: 10 × 4^N + 2

After Dual Mesh, output faces = input vertices.  Level 3 → 642 Voronoi cells.
Most cells are hexagonal (degree-6 vertices of the ico sphere); exactly 12
cells are pentagonal (the 12 original ico vertices, which have degree 5).
