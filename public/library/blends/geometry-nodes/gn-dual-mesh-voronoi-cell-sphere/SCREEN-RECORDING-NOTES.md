# Screen Recording Notes — GN Dual Mesh: Voronoi Cell Sphere

## Software
OBS Studio (recommended) or Windows Game Bar (Win+G).

## Scene setup before recording
1. Open `voronoi_cell_sphere.blend` (generated by `blueprint.py`).
2. In the Properties panel ▸ Object Properties ▸ Modifiers ▸ VoronoiCellSphere:
   - Set **Noise Strength** to **0.0** — you should see a regular geodesic pattern.
3. Switch to **Rendered** viewport (numpad `/` or press `Z` → Rendered).
4. Zoom to fill the viewport with the sphere (numpad `Numpad .`).

## What to record
A two-part demo works best:

### Part 1 — Topology explanation (~30 s)
- Start with Noise Strength = 0.0 (uniform hexagon/pentagon cells).
- In the Geometry Nodes editor, zoom in on the **Dual Mesh** node.
- Slowly drag **Noise Strength** from 0.0 → 0.14 in the modifier panel while
  watching the viewport: narrate that vertex jitter → organic cell irregularity.
- Return to 0.08 (the default value used in `blueprint.py`).

### Part 2 — Node walkthrough (~45 s)
- In the GN editor, pan left-to-right through the full node chain:
  IcoSphere → SetPosition (noise) → DualMesh → ScaleElements → ExtrudeMesh
  → SetShadeSmooth → SetMaterial.
- Pause on **DualMesh** and explain the topological dual.
- Pause on **ScaleElements** (FACE domain) — show the cell-gap effect by
  toggling the Scale value between 1.0 (touching) and 0.85 (gapped).
- Pause on **ExtrudeMesh** — toggle Individual Faces True/False to show the
  difference between individual tile extrusion and shell extrusion.

| Resolution         | 1920×1080                            |

## Tips
- Hide the Blender top bar (View ▸ Toggle Topbar) for a cleaner frame.
- Use the Node Wrangler add-on's Ctrl+Shift+Click to preview intermediate
  nodes — very effective for showing what DualMesh produces before ScaleElements.
- The camera in the .blend file is already positioned; use Numpad 0 to enter
  camera view for the Part 1 orbit render preview.
