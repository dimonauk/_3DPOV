# GN Socket Panels — NodeTreeInterfacePanel API (Blender 5.1)

**Topic:** Organising Geometry Nodes group inputs into collapsible panels in the modifier UI using `NodeTreeInterfacePanel` (Blender 5.0+).

**Licence:** CC0 · Holoflow Studio

## What this produces

A `HF_PoiEnergyRibbon` GN modifier applied to a spiral helix curve.
The modifier exposes ten parameters organised into three collapsible sections:

| Panel | Sockets | Closed? |
|---|---|---|
| Curve Shape | Resample Count, Profile Resolution | open |
| Noise Displacement | Scale, Strength, Detail, Roughness | open |
| Ribbon | Ribbon Radius, Fill Caps | **closed** |

## Key API (Blender 5.0+)

```python
panel = node_group.interface.new_panel("Noise Displacement", default_closed=False)
s = node_group.interface.new_socket("Noise Scale", in_out='INPUT',
    socket_type='NodeSocketFloat', parent=panel)
```

## Files

| File | Purpose |
|---|---|
| `blueprint.py` | Builds entire GN tree + panels from Python |
| `record.py` | Animates Noise Scale for viewport.mp4 |
| `SCREEN-RECORDING-NOTES.md` | OBS instructions for screen.mp4 |
| `hf_poi_energy_ribbon.glb` | (generated by blueprint.py + _export()) |

## Quick start

1. Open Blender 5.1 → Scripting workspace.
2. Open and run `blueprint.py`.
3. Select the `hf_poi_energy_ribbon` object.
4. In the Properties panel → Modifier Properties, inspect the three
   collapsible sections.
5. Open and run `record.py` to generate `viewport.mp4`.
