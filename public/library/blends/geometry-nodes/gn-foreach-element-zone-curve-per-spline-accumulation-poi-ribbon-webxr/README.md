# GN Foreach Element Zone — Per-Spline Poi Ribbon (Blender 5.1)

The **Foreach Element Zone** (stable in Blender 5.1) iterates over geometry
elements one at a time inside a Geometry Nodes modifier.  When the domain is
set to **Spline**, each loop iteration receives a single-spline Curves object —
letting you compute per-strand statistics and build per-strand geometry that
would otherwise require separate objects or Python bpy scripting.

This entry builds 8 helical poi light-painting strands, converts each to a
ribbon mesh whose width is proportional to the strand's arc length, and assigns
a distinct emission material per strand.  The result exports as a Draco-6 GLB
for WebXR bloom display.

## Artefacts

| File | Description |
|------|-------------|
| `blueprint.py` | Full Python script — builds Curves, GN modifier, materials, exports GLB |
| `record.py` | Renders a 90-frame viewport animation of the rotating ribbon bundle |
| `hf_poi_ribbons.blend` | Blender scene (generated by blueprint.py) |
| `hf_poi_ribbons.glb` | Draco-6 GLB for WebXR (generated by blueprint.py) |
| `SCREEN-RECORDING-NOTES.md` | OBS instructions for capturing the screen recording |

## Run order

```
blender --background --python blueprint.py
blender --background hf_poi_ribbons.blend --python record.py
```

## Blender 5.1 node IDs used

- `GeometryNodeForeachGeometryElementInput` / `…Output`
- `GeometryNodeSplineLength`
- `GeometryNodeResampleCurve`
- `GeometryNodeCurvePrimitiveCircle`
- `GeometryNodeCurveToMesh`
- `GeometryNodeSetMaterialIndex`
- `GeometryNodeSetShadeSmooth`
- `ShaderNodeMath` (MULTIPLY_ADD)
