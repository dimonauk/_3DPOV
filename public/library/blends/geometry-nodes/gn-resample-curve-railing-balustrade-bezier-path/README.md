# GN Resample Curve — Parametric Railing & Balustrade Along a Bézier Path

**Topic:** Geometry Nodes · Resample Curve (LENGTH mode) · Instance on Points  
**Blender version:** 5.1  
**Licence:** CC0  
**Category:** geometry-nodes  
**Slug:** `gn-resample-curve-railing-balustrade-bezier-path`

## What this builds

A fully parametric interior railing system: baluster posts spaced at a
user-controlled interval along any Bézier curve, with a cylindrical handrail
tube running along the top.  The Post Spacing value is in metres — reshape the
path and the spacing stays physically constant.  Output: `railing_balustrade.glb`
(Draco 6, Y-up) for WebXR interior environments.

## Key nodes

| Node | Role |
|------|------|
| **Resample Curve** (mode=LENGTH) | Uniform physical spacing between sample points |
| **Curve to Points** (mode=EVALUATED) | Extract position, tangent, rotation per point |
| **Instance on Points** | Scatter baluster geometry on the point cloud |
| **Align Euler to Vector** (axis=Z) | Orient each post along the curve direction |
| **Realize Instances** | Flatten instances before GLB export |
| **Curve to Mesh** + Circle profile | Cylindrical handrail tube |

## Why LENGTH mode matters

Using COUNT mode on Curve to Points directly ties baluster count to the
number of control segments.  Reshaping the curve compresses or stretches
spacings proportionally.  With Resample Curve (LENGTH) first, the interval is
always `Post Spacing` metres — art-direction and editing become independent.

## Parameters (top of blueprint.py)

| Name | Default | Description |
|------|---------|-------------|
| `POST_SPACING` | 0.50 m | Physical gap between baluster centres |
| `RAIL_RADIUS`  | 0.025 m | Handrail tube outer radius |
| `POST_W`       | 0.022 m | Baluster cross-section half-width |
| `POST_H`       | 0.900 m | Floor to underside of rail |
