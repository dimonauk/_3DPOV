# GN Distribute Points on Faces + Instance on Points
## Procedural Crystal Garden Scatter — Blender 5.1

Demonstrates the canonical GN scatter pattern: **Distribute Points on Faces** (Poisson Disk mode) placed on a hexagonal terrain, **Instance on Points** picking randomly from three crystal spike variants, surface-normal alignment from the Rotation socket, per-instance scale variation via **FunctionNodeRandomValue**, and **Realize Instances** before GLB export.

| File | Description |
|------|-------------|
| `blueprint.py` | Full bpy + bmesh script — creates crystals, terrain, GN tree, exports GLB |
| `record.py` | Viewport animation recorder — orbiting camera + seed animation, renders viewport.mp4 |
| `SCREEN-RECORDING-NOTES.md` | OBS instructions for screen.mp4 |
| `hf_crystal_scatter.blend` | Saved scene (generated by blueprint.py) |
| `hf_crystal_scatter.glb` | Draco L6 + WebP GLB for WebXR |

## Run order

```bash
blender --background --python blueprint.py
blender hf_crystal_scatter.blend --background --python record.py
```

## Key nodes

- `GeometryNodeDistributePointsOnFaces` — `distribute_method = 'POISSON_DISK'`
- `GeometryNodeInstanceOnPoints` — `Pick Instance = True`
- `GeometryNodeCollectionInfo` — feeds crystal collection as instance pool
- `FunctionNodeRandomValue` (FLOAT + INT) — scale and variant index
- `GeometryNodeRealizeInstances` — mandatory before GLB export
