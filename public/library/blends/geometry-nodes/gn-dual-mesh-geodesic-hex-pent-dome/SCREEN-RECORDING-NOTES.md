## Blender Layout Before Recording

1. Open a fresh Blender 5.1 scene (General template).
2. Set **Viewport Shading → Material Preview** (press `Z` → Material Preview).
3. Set **Overlays → Wireframe** ON (so you can see the topology change).
4. Delete default cube.

## Recording Script (steps to perform on camera)

### Beat 1 — Add icosphere (0:00–0:30)
- Press `Shift+A` → Mesh → Ico Sphere.
- In the **Operator Panel** (F9 or bottom-left panel), set **Subdivisions = 4**.
- Press `G`, `Z`, `0` to confirm it is at origin.
- Show the plain triangulated surface from 3–4 camera angles.
- Narrate: "This is a 4-subdivision icosphere — 80 triangular faces."

### Beat 2 — Add Geometry Nodes modifier (0:30–1:30)
- With icosphere selected, open **Properties → Modifier** (blue wrench).
- Click **Add Modifier → Geometry Nodes**.
- Click **New** to create a blank node tree.
- Open the **Geometry Node Editor** (split a viewport).
- Add a **Dual Mesh** node (`Shift+A` → Mesh → Dual Mesh).
- Wire: **Group Input → Dual Mesh → Group Output**.
- Pan over the viewport: the triangles have become hex and pent cells.
- Narrate: "Every triangular face became a vertex; every vertex became a face."

### Beat 3 — Add Merge by Distance (1:30–2:00)
- After Dual Mesh, insert **Merge by Distance** (distance = 0.001 m).
- Show that seam vertices are fused; mesh count drops slightly in the N-panel.

### Beat 4 — Detect pentagons with Face Neighbors (2:00–3:00)
- Add **Face Neighbors** node — show `Vertex Count` output.
- Add **Compare** (INT, EQUAL, B = 5).
- Add **Set Material Index** (index = 1), Selection ← Compare result.
- Pre-create two materials on the object (teal hex, coral pent).
- Switch viewport to **Material Preview** — 12 coral pentagons appear.
- Narrate: "Euler's formula guarantees exactly 12 pentagons — always, at any
  subdivision depth."

### Beat 5 — Store Named Attribute & export (3:00–4:00)
- Add **Store Named Attribute** (domain = Face, name = `holoflow:facet`, value = 1.0).
- Show **Geometry Spreadsheet** confirming the attribute on all faces.
- Apply modifier, shade flat, export via **File → Export → glTF 2.0**.
- Drag resulting `.glb` into Three.js viewer or browser tab if available.

## Tips
- Keep the Geometry Node editor visible alongside the 3D viewport so
  viewers can read the node graph as you build it.
- Zoom the node editor so all four nodes (Dual Mesh, Merge, Face Neighbors,
  Set Material Index) are legible simultaneously — resize to ~70% zoom if
  needed.
- After adding the Dual Mesh node, orbit the viewport to show a front view
  of the dome so the hex/pent pattern reads clearly.
