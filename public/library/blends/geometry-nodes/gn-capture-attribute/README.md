# GN Capture Attribute + Named Attribute — Per-Instance Data Pipelines

**Blender 5.1 | CC0 | Holoflow Studio**

Geometry Nodes fields are *lazy* — they describe how to compute a value, not
what the value is.  The same `Index` field evaluated at POINT domain on a
scatter cloud gives 0..N-1 per scatter point.  Evaluated at INSTANCE domain
after `InstanceOnPoints`, it still gives 0..N-1 — by coincidence, since
instance indices happen to match the original point order in a simple pipeline.

Add a deletion step between scatter and instancing (or a Boolean merge, or a
JoinGeometry) and the indices shift.  Any field expression re-evaluated after
the reorder gives different values from the ones computed at scatter time.

**`Capture Attribute`** is the solution: it forces the field expression to
evaluate *now*, at the current domain, and stores the result as a concrete
attribute.  That attribute propagates through any subsequent operations intact.

## What this blueprint builds

A 4 × 4 m scatter field of ~64 flat-shaded ico-spheres, each a different
hue derived from the scatter point's original random index.  The hue assignment
uses the `CaptureAttribute → StoreNamedAttribute` pipeline so it is immune to
any downstream point deletions or reorders.  The material reads `colour_phase`
via `ShaderNodeAttribute` and maps it through a 6-stop rainbow ColorRamp.

## Key concepts

- **Field laziness**: nodes like `Index`, `Position`, `RandomValue` are field
  expressions, not values.  They re-evaluate at the active domain.
- **Capture Attribute**: evaluates a field expression at a specific domain and
  stores the result as an attribute.  Downstream operations see the stored
  value, not a re-evaluation.
- **Store Named Attribute**: writes any attribute (or field) to the mesh under
  a string name.  Appears in the Spreadsheet editor.  Survives `export_apply`.
- **INSTANCE → POINT propagation**: after `RealizeInstances`, each instance's
  attributes are copied to every vertex of the realized mesh for that instance.
  `ShaderNodeAttribute` reads the result at POINT domain in the material.
