## What to record

1. **Open** `colour_scatter.blend` (generated by `blueprint.py`).
2. In the top-right of the 3D viewport set shading to **Material Preview**.
   The scatter field should appear — ~64 coloured spheres.
3. **Spreadsheet editor** (split the screen):
   - Set domain to **Instance** and show `colour_phase` column.
   - Scrub to confirm each instance has a distinct float value.
4. **Node editor** — walk through the node tree left to right:
   - MeshGrid → DistributePointsOnFaces → Index/RandomValue
   - **CaptureAttribute** (pause here — explain the domain freeze)
   - IcoSphere → SetMaterial → InstanceOnPoints
   - **StoreNamedAttribute** (pause — show the 'colour_phase' name)
   - RealizeInstances → SetShadeSmooth
5. **Delete a cull test** (optional live demo of the problem):
   - Temporarily insert a `DeleteGeometry` node before `InstanceOnPoints`
     that deletes every other point (`Index % 2 == 0`).
   - WITHOUT `CaptureAttribute` wired: show how the colours shift.
   - WITH `CaptureAttribute` wired: show colours stay stable.
6. **Material nodes** — show `ShaderNodeAttribute` reading `colour_phase`.
7. Orbit the 3D viewport (middle-mouse drag) to show all spheres.

## Duration target

3–5 minutes.  Pause on the Capture Attribute node for at least 30 seconds.
