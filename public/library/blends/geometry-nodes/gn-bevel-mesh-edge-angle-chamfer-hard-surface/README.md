# GN Bevel Mesh + Edge-Angle Limit
## Selective Hard-Surface Chamfer for WebXR — Blender 5.1

Chamfered edges read as manufactured precision at any polygon count. The **Bevel
Mesh** geometry node (Blender 4.0+, refined in 5.1) places a chamfer strip on edges
whose dihedral angle exceeds a threshold — 90° box corners yes, shallow triangulation
seams no. The result is exported via Draco-compressed GLB for WebXR.

---

### Why this matters for WebXR

Hard-surface props in WebXR run at low polygon budgets (< 5,000 triangles per prop).
At that density, sharp 90° corners on sci-fi panels look toy-like and aliased. A 1.8 cm
chamfer — two loop cuts, flat profile — is nearly zero triangle overhead (it adds one
edge loop per bevelled edge) and reads as precision engineering under any lighting.

Baking the chamfer into the GLB vertex buffer (via `export_apply=True`) means the
WebXR runtime sees a slightly denser but geometrically richer mesh rather than having
to interpret a normal map. At LOD 0 this is the right trade-off.

### Output artefacts (generated by running blueprint.py)

- `hs_control_panel.blend` — saved via File > Save after running the script
- `hs_control_panel.glb` — Draco-compressed, Y-up, apply_transforms=True

---

### Key parameters (edit at top of blueprint.py)

| Constant | Default | Effect |
|----------|---------|--------|
| `BEVEL_WIDTH` | `0.018` | Chamfer width in metres |
| `ANGLE_THRESHOLD` | `25°` | Min dihedral angle to bevel |
| `SEGMENTS` | `2` | Loop cuts per bevel strip |
| `PROFILE` | `1.0` | 1.0=flat chamfer, 0.5=convex bead |
