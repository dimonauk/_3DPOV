# GN Raycast — Terrain-Following Decal Scatter
**Blender 5.1 · CC0 · Holoflow Studio**

Flat quad decals that lie flush to any curved mesh surface using the Geometry Nodes
Raycast node.  No UV projection, no baking, no texture-space tricks.

## How it works

A grid of points is distributed above the terrain (`EMITTER_HEIGHT = 2.0 m`).  
The Raycast node fires one ray straight down per point and intersects it against
the terrain mesh (imported via Object Info with `transform_space = 'RELATIVE'`).
Hit Position replaces each point's location; Hit Normal drives `AlignEulerToVector`
to orient the instance's +Z toward the surface.  Points that miss the terrain
(boundary rays) are deleted by `DeleteGeometry` before instantiation.

## Running

1. Open Blender 5.1.  
2. Open `blueprint.py` in the Script editor and click **Run Script**.  
3. Save the result as `terrain_decal_scatter.blend`.  
4. Open `record.py` and click **Run Script** to render `viewport.mp4`.  
5. For `screen.mp4`, follow `SCREEN-RECORDING-NOTES.md`.

## Key parameters

| Constant | Default | Effect |
|----------|---------|--------|
| `TERRAIN_DISP_STR` | `0.42` | Terrain height variation |
| `EMITTER_HEIGHT` | `2.0` | Ray origin altitude |
| `SCATTER_DIST_MIN` | `0.14 m` | Minimum gap between decals |
| `DECAL_HALF` | `0.09 m` | Half-size of each decal quad |
| `SCALE_MIN / MAX` | `0.55 / 1.50` | Per-decal random size range |
