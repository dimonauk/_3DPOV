# GN Trim Curve — Animated Line-Draw Reveal Effect

**Blender 5.1 | CC0 | Topic: geometry-nodes | Slug: gn-trim-curve-line-draw**

## What this builds

A golden Archimedean spiral that writes itself outward from the centre over 60
frames. The reveal is driven by keyframing the `Draw_End` group socket (0 → 1) on
the Trim Curve node in FACTOR mode. Exports a Draco-compressed GLB of the
full spiral for Three.js / WebXR static delivery.

## Files

| File | Purpose |
|---|---|
| `blueprint.py` | Creates the full scene, keyframes the animation, saves `.blend` + `.glb` |
| `record.py` | Renders 60 frames to `viewport.mp4` using EEVEE opengl viewport render |
| `SCREEN-RECORDING-NOTES.md` | OBS instructions for the `screen.mp4` capture |
| `spiral_trace.blend` | Blender file (generated by `blueprint.py`) |
| `spiral_trace.glb` | Draco-compressed GLB at frame 60 (full spiral) |

## How to run

```bash
# From a Blender-aware Python environment, or via Blender --background:
blender --background --python public/library/blends/geometry-nodes/gn-trim-curve-line-draw/blueprint.py
```

Then, for the viewport animation:
```bash
blender --background --python public/library/blends/geometry-nodes/gn-trim-curve-line-draw/record.py
```

## Key nodes

- `GeometryNodeCurvePrimitiveSpiral` — Archimedean spiral, Height=0 (flat)
- `GeometryNodeTrimCurve` mode=FACTOR — clips [Start, End] on normalised [0,1] scale
- `GeometryNodeCurvePrimitiveCircle` Resolution=8 — octagonal tube profile
- `GeometryNodeCurveToMesh` — sweeps profile along trimmed arc
- `GeometryNodeSetShadeSmooth` domain=FACE — cylindrical silhouette
