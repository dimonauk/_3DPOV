# GN Instance on Points — Scatter Patterns

**Topic**: geometry-nodes  
**Blender version**: 5.1  
**Technique**: Distribute Points on Faces → Instance on Points → Realize Instances

---

## What this entry covers

Scatter a tile geometry across a surface using Blender 5.1's Geometry Nodes
`Instance on Points` workflow.  The result is a procedural scatter panel:
hundreds of flat diamond tiles positioned by a Poisson-disk distribution,
each tile randomly rotated, all collapsed to a single mesh for GLB export.

This is the native GN alternative to the Tissue add-on's Tessellate operator.
The two approaches share the same intent — tile a component across a surface —
but differ in control: Tissue offers tight per-face projection, GN offers
density and distribution control without topology dependency.

## Running

```bash
# Blueprint (produces output/instance_scatter.glb)
blender --background --python blueprint.py

# Recording (produces public/library/videos/geometry-nodes/instance-on-points/viewport.mp4)
blender --background --python record.py
```

## The node graph

```
Group Input
  └─ Geometry ──► Distribute Points on Faces (Poisson, density=6/m²)
                    └─ Points ──► Instance on Points ──► Rotate Instances ──► Realize Instances ──► Group Output
                                               │
                         Object Info (tile) ───┘
```

The `Realize Instances` node is mandatory before GLB export.  Without it
the glTF exporter receives the instance geometry tree and silently produces
an empty file.

## Blender 5.1 notes

- `tree.interface.new_socket()` — the 4.0+ API for GN I/O sockets.
  `tree.inputs.new()` was removed; do not use it.
- Node types in 5.1:
  - `GeometryNodeDistributePointsOnFaces`
  - `GeometryNodeInstanceOnPoints`
  - `GeometryNodeRealizeInstances`
  - `GeometryNodeRotateInstances`
  - `FunctionNodeRandomValue`
- Poisson distribution (`POISSON` method) replaces the deprecated
  `RANDOM` for uniform scatter; it was the default in 4.x and stays
  the default in 5.x.
