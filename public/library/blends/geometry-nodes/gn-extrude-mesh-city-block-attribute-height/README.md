# GN Extrude Mesh — City Block: Per-Face Noise-Height Tower Extrusion

**Blender 5.1 · CC0 · Holoflow Studio**

Builds a low-poly city block from a 12×12 grid by extruding each face
independently to a White Noise–driven height.  Demonstrates the
`Offset Scale` field socket on `GeometryNodeExtrudeMesh` — the mechanism
that turns a uniform extrusion into an attribute-driven per-element operation.

## What it builds

- `hs_city_block` mesh object with GN modifier `HS_CityBlock`
- 144 face lots (12×12 grid, 10 m block)
- 75% of lots extruded to random heights between 0.5 m and 6.0 m
- 3 materials: `hs_ground` (green), `hs_wall` (mid grey), `hs_rooftop` (warm gold)
- Flat-shaded for faceted low-poly WebXR aesthetic

## Key technique

The expert insight is in the `Offset Scale` socket: it accepts a **per-face
FLOAT field**, not just a uniform value.  Wiring `WhiteNoise.Value` →
`MapRange` → `Offset Scale` gives every lot a unique height from a single
node — no per-face custom attribute setup required.

The `use_individual_faces = True` flag (`Individual` in the UI) is equally
critical: without it, adjacent selected faces merge their extrusions into one
shared slab.  With it, each lot extrudes as its own isolated column.
