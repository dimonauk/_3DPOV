# GN UV Unwrap + Pack Islands — Crystal Geode with Procedural UV

**Blender 5.1** · Geometry Nodes · `GeometryNodeUVUnwrap` + `GeometryNodePackUVIslands`

## What this teaches

UV coordinates are almost always generated outside the modifier stack — you unwrap
manually, lock the UV map, then apply your GN modifier on top.  That works until the
modifier changes vertex count or topology, at which point the UV map is orphaned and
you must unwrap again.

`GeometryNodeUVUnwrap` (Blender 4.1+) solves this: it generates UV coordinates
*inside* the GN modifier, after all subdivision and displacement.  Combined with
`GeometryNodePackUVIslands`, which optimally packs the resulting face islands into
the 0–1 UV square, you get a fully procedural UV pipeline that self-repairs whenever
the geometry changes.  Store the result as a Named Attribute called `"UVMap"` in
the `CORNER` domain with `FLOAT2` data type, and glTF-Blender-IO exports it
automatically as `TEXCOORD_0` — the slot Three.js, Babylon.js, and WebXR runtimes
read for texture sampling.

## Node architecture

```
GroupInput ──────────────────────────────────────────────────────►
              │Geometry      │Displacement   │Seam Angle Degrees
              ▼              │               │
         SubdivideMesh       │               ▼
              │              │          RADIANS
              ▼              │               │
         SetPosition ◄── VectorMath(SCALE)  │
           Offset           ▲    ▲           │
                        Normal  (Fac-0.5)×D │
                                ▲            │
                           ShaderNoise   EdgeAngle.Unsigned
                                              │
                                        GREATER_THAN ◄──────────
         SetShadeSmooth(smooth=False)         │
              │                         UVUnwrap ◄── Seam bool
              │                              │
              ▼  Geometry               PackUVIslands
         StoreNamedAttribute ◄── Value ─────┘
         (domain=CORNER, FLOAT2, "UVMap")
              │
         GroupOutput
```

## Seam angle tuning

`SEAM_ANGLE_DEG = 42` is the operative parameter.  The `GeometryNodeEdgeAngle`
node evaluates the dihedral angle between adjacent face normals per edge.  Any edge
whose unsigned angle exceeds the threshold becomes a seam cut.

| Threshold | Effect |
|-----------|--------|
| 20–30° | Many small islands, UV space wasted on small faces |
| 35–50° | Good balance for organic noise-displaced surfaces |
| 60–80° | Few large islands, more angular distortion |
| > 90° | Wraps around high-curvature areas, severe stretch |

After changing the threshold, `PackUVIslands` automatically repacks — no manual
step required.

## TEXCOORD_0 export contract

glTF-Blender-IO maps Named Attributes to glTF mesh primitive attributes:

| Attribute name | Domain | Data type | glTF accessor |
|----------------|--------|-----------|--------------|
| `UVMap`        | CORNER | FLOAT2    | TEXCOORD_0   |
| `UVMap.001`    | CORNER | FLOAT2    | TEXCOORD_1   |
| `_ELEVATION`   | POINT  | FLOAT     | _ELEVATION (custom) |

**`export_apply=True` is mandatory.**  Without it the GN modifier is skipped and
the GLB contains no UV.  The `export_attributes=True` flag is also required for
Named Attributes (as opposed to mesh UV layers generated outside GN).
