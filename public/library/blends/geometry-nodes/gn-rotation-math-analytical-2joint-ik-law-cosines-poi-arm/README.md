# GN — Analytical 2-Joint IK: Law of Cosines Solver

**Blender 5.1 · CC0 · Holoflow Studio**

Geometry Nodes modifier that computes two joint angles from a target position
in closed form — no Simulation Zone, no iterative solver.

## What it does

Given an Empty object as the IK target, the `HF_2JointIK` modifier:

1. Reads the target's position relative to the arm object.
2. Computes d = distance(root, target).
3. Resolves the **elbow angle** θ_e via the law of cosines.
4. Resolves the **shoulder angle** φ₁ = atan2(ty, tx) − β.
5. Derives the **lower-arm world angle** φ₂ = φ₁ + π − θ_e.
6. Builds the arm geometry: two tube segments, an elbow sphere, a poi-head sphere.

## Usage

```bash
blender --background --python blueprint.py
blender --background hf_2joint_ik.blend --python record.py
```

Move the `PoiTarget` empty anywhere within the reach envelope
(d ≤ L1 + L2 = 2.7 m) and the arm tracks in real time.

## Elbow-up vs elbow-down

Change `ELBOW_SIGN` in `blueprint.py`:
- `-1` → elbow-up (default, more natural for overhead poi throws)
- `+1` → elbow-down (suitable for waist-level tracking)

## Parameters

| Name | Default | Notes |
|------|---------|-------|
| `L1` | 1.50 m | Upper arm length |
| `L2` | 1.20 m | Lower arm length |
| `ARM_R` | 0.055 m | Tube radius |
| `JOINT_R` | 0.09 m | Elbow sphere radius |
| `POI_R` | 0.19 m | Poi-head sphere radius |
