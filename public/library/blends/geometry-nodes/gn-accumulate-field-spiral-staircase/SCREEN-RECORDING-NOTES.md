# Screen Recording Notes — GN Accumulate Field: Spiral Staircase

## Software

| Setting | Value |
|---|---|
| Capture tool | OBS Studio or Windows Game Bar (Win+G) |
| Window source | Blender 5.1 application window |
| Resolution | 1920 × 1080 |
| Frame rate | 30 fps |
| Audio | Off |
| Output format | MP4 (H.264) |
| Output file | `public/library/videos/geometry-nodes/gn-accumulate-field-spiral-staircase/screen.mp4` |

## Scene to record

Open `spiral_staircase.blend` (generated by `blueprint.py`).

## Shot sequence

1. **Overview (0–10 s)** — 3D Viewport in Material Preview. Camera already at
   the orbit position set by the blueprint. Press Space to play the 4-second
   orbit animation. Let it loop 2–3 times so viewers see every tread.

2. **GN editor wide (10–20 s)** — Switch to the Geometry Nodes workspace
   (top header: Geometry Nodes tab). Show the full node tree: MeshLine →
   SetPosition → InstanceOnPoints → RotateInstances → SetMaterial →
   RealizeInstances. Pan slowly left-to-right.

3. **AccumulateField zoom (20–35 s)** — Zoom into the two AccumulateField
   nodes (Cumul. Height and Cumul. Rotation). Show both `Leading` outputs
   wired into CombineXYZ nodes. Hover over the `Leading` output of each
   AccumulateField to display the socket tooltip confirming the data type (Float).

4. **Value change demo (35–50 s)** — With the `Cumul. Height` AccumulateField
   selected, scrub the `Value` input from 0.15 down to 0.05 and back up to
   0.30. Switch to the 3D Viewport (keep Geometry Nodes editor visible in a
   split) and watch the staircase flatten and steepen in real time.

5. **Twist change demo (50–65 s)** — Select the `Cumul. Rotation` AccumulateField.
   Change `Value` from `0.3927` (22.5°) to `0.7854` (45°). Staircase
   compresses to half-revolution. Change to `0.1963` (11.25°): staircase
   expands to two full revolutions. Return to `0.3927`.

6. **Close-out (65–75 s)** — Switch to Rendered preview (Z → Rendered) for
   a final beauty pass of the concrete treads and steel post under the area
   light. Press Space to let the orbit animation play.

## Tips

- If the GN node tree is blank on open: click the StaircaseScaffold object in
  the 3D Viewport, then confirm the active node group in the Geometry Nodes
  header dropdown.
- Material Preview mode (Solid + MatCap fallback): press Z → Material Preview.
- To reset parameter changes: Ctrl+Z in the GN editor.
