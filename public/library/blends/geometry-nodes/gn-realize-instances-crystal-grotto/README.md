# Crystal Grotto — GN Realize Instances

**Blender 5.1 · CC0 · Holoflow Studio**

Scatter 110 hexagonal crystal shards across a sphere surface using Instance on Points,
assign a unique hue to each crystal with Capture Attribute, then collapse all instances
into exportable vertex geometry with Realize Instances.  The per-instance colour
survives realization as a named vertex attribute that drives emission in the material.

## What it demonstrates

- `GeometryNodeRealizeInstances` — the node that converts a lightweight instance list
  into a real, Draco-compressible vertex buffer.
- The order law: `CaptureAttribute(domain=INSTANCE)` must precede `RealizeInstances`.
  Placing it after causes the random field to evaluate per-vertex, destroying the
  one-colour-per-crystal intent.
- `StoreNamedAttribute(domain=POINT, name='crystal_hue')` gives the captured value
  a stable name the material's `ShaderNodeAttribute` can read.
- `export_attributes=True` in the glTF exporter writes `_crystal_hue` as a custom
  vertex accessor, readable in Three.js as `geometry.attributes['_crystal_hue']`.

## Running

```bash
# Open Blender, load and run blueprint.py via the Text Editor
# Then render the viewport clip:
blender crystal_grotto.blend --background --python record.py
```
