# GN Edge Angle Crease + Subdivision Surface

**Blender 5.1 · Geometry Nodes · CC0**

Writes the `crease_edge` float attribute (EDGE domain) from each edge's
unsigned dihedral angle using a parametric threshold slider.  A Subdivision
Surface modifier placed after the GN modifier reads the attribute via
OpenSubdiv's Catmull-Clark implementation — sharp where crease=1, smooth
where crease=0.

## Quick start

```bash
# 1. Generate blend + GLB
blender --background --python blueprint.py

# 2. Record the viewport animation
blender edge_crease_hard_surface.blend --background --python record.py

# 3. Screen-record interactively (see SCREEN-RECORDING-NOTES.md)
blender edge_crease_hard_surface.blend
```

## Technique notes

- **crease_edge attribute name**: Blender 4.0+ canonical name on the EDGE
  domain.  Pre-4.0 code used `edge.crease` on BMesh objects — that field is
  now a live view over this attribute, not primary storage.
- **Modifier stack order is critical**: the GN modifier must precede the
  Subdiv modifier.  GN writes `crease_edge`; Subdiv reads it.  Reversing them
  produces a subdivided mesh with no creases.
- **Blend Width**: the soft ±7.5° band around the threshold prevents a hard
  binary jump from smooth to sharp.  At the midpoint of the band, edges receive
  crease=0.5 — a semi-sharp result that reads as a bevelled edge through subdiv
  without inserting any bevel geometry.
- **GLB export**: `export_apply=True` bakes the full stack.  The exported mesh
  is fully subdivided with hard normals at creased edges.  Suitable for any
  WebXR runtime or Three.js scene.
