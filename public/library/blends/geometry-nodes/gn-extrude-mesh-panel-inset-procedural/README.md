# GN Extrude Mesh — Procedural Panel Inset

**Blender 5.1 · Geometry Nodes · CC0**

Builds a 16 × 16 face grid whose faces are stochastically extruded outward
in two tiers. The `Extrude Mesh` node's `Top` and `Side` output sockets drive
downstream edge-crease marking and nested selection, producing a sci-fi
surface panel look with hard SubD edges — no manual edge loops required.

## Files

| File | Purpose |
|---|---|
| `blueprint.py` | Full bpy script — builds scene, GN tree, SubDiv modifier, exports GLB |
| `record.py` | Viewport animation — Panel Depth then Inner Depth animate, camera orbits |
| `SCREEN-RECORDING-NOTES.md` | OBS instructions for the screen-capture tutorial video |
| `panel_inset.blend` | Source file (generated by blueprint.py) |
| `panel_inset.glb` | Draco GLB for WebXR (generated by blueprint.py) |

## Quick Start

```bash
blender --background --python blueprint.py
blender --background panel_inset.blend --python record.py
```

## Key Nodes

- `Extrude Mesh` (mode=FACES, Individual=True) — per-face normal extrusion
- `Extrude Mesh.Side` — boolean field selecting hinge-edge side walls
- `Extrude Mesh.Top`  — boolean field selecting extruded face caps
- `Set Edge Crease`   — writes crease=1.0 to Side edges for SubDiv sharpness
- `Random Value` (FLOAT, per-face) + `Compare` — stochastic face selection
- `Boolean Math AND`  — intersects Top field with random inner selection

## Parameters (modify at top of blueprint.py)

| Constant | Default | Effect |
|---|---|---|
| `PANEL_THRESHOLD` | 0.38 | Fraction of faces raised (0 = none, 1 = all) |
| `PANEL_DEPTH` | 0.030 m | Height of first-tier panels |
| `INNER_THRESHOLD` | 0.50 | Fraction of first-tier caps with second tier |
| `INNER_DEPTH` | 0.014 m | Height of second-tier caps above first tier |
| `CREASE` | 1.0 | Edge crease for SubD sharpness (0 = soft, 1 = sharp) |
