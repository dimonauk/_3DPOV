# GN Mesh to Curve + Curve to Mesh — Procedural Bevelled Wireframe Scaffold

**Blender 5.1 · Geometry Nodes · CC0**

Converts every edge of an icosphere into a bevelled tube whose diameter is
proportional to the dihedral angle at that edge.  Sharp structural edges become
thick members; flat seams become thin wires.  The pipeline demonstrates the
full EDGE → SPLINE → POINT domain-conversion chain in Geometry Nodes.

## Files
| File | Description |
|------|-------------|
| `blueprint.py` | Builds the scene and GN tree programmatically; exports GLB |
| `record.py` | Viewport-animation recorder (camera orbit + tube growth) |
| `SCREEN-RECORDING-NOTES.md` | OBS/Game Bar instructions for `screen.mp4` |
| `wireframe_scaffold.blend` | Generated by `blueprint.py` |
| `wireframe_scaffold.glb` | WebXR-ready export (Draco 6, WebP, +Y up) |

## Usage
```bash
# Generate the .blend and .glb
blender --background --python blueprint.py

# Record the viewport animation
blender wireframe_scaffold.blend --background --python record.py
```

## Key technique
```
IcoSphere(r=1.0, subdiv=2)
  → StoreNamedAttribute("edge_sharpness", EDGE, EdgeAngle.unsigned)
  → MeshToCurve                      # edge_sharpness now at SPLINE domain
  → FieldOnDomain(SPLINE → POINT)    # broadcast to both spline endpoints
  → MapRange([0,π] → [THIN_R, THICK_R])
  → SetCurveRadius
  → CurveToMesh × CurveCircle(r=1.0, verts=8, Fill Caps=True)
  → MergeByDistance(0.003)           # weld tube junctions
  → SetShadeSmooth → SetMaterial
```

## Parameters (modifier panel)
| Parameter | Default | Effect |
|-----------|---------|--------|
| Thin Radius | 0.012 m | Tube radius on near-flat edges |
| Thick Radius | 0.040 m | Tube radius on sharp-angle edges |
