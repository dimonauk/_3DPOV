# Screen Recording Notes — GN Mesh to Curve + Curve to Mesh: Wireframe Scaffold

## Software
OBS Studio (recommended) or Windows Game Bar (Win+G).

## Scene setup before recording
1. Open `wireframe_scaffold.blend` (generated by `blueprint.py`).
2. In Properties ▸ Object Properties ▸ Modifiers ▸ WireframeScaffold:
   - Set **Thick Radius** to **0.002** — scaffold should appear as hairlines.
3. Switch to **Rendered** viewport (Z → Rendered).
4. Use Numpad 0 for camera view; numpad `.` to frame the scaffold.

## What to record

### Part 1 — Live parameter demo (~25 s)
- With Thick Radius = 0.002, drag it slowly up to 0.040 in the modifier panel.
- The viewer sees the tubes grow from hairlines to structural members while the
  dihedral-based hierarchy becomes visible: edges where two faces meet at a
  sharp angle are noticeably fatter than the near-flat equatorial seams.
- Return to 0.040 (default from blueprint.py).

### Part 2 — Node tree walkthrough (~50 s)
Open the Geometry Nodes editor. Pan left → right through the chain:
- **IcoSphere**: show the source mesh briefly (Ctrl+Shift+Click the node to
  preview it in the 3D viewport via Node Wrangler).
- **Store Named Attribute** (edge_sharpness, EDGE domain): explain that you
  are saving data at the edge level before topology changes.
- **Mesh to Curve**: preview to show the raw edge-splines (they look like the
  original wireframe, but the data is now curves).
- **Evaluate on Domain** (SPLINE → POINT): this is the key node; explain why
  it is necessary — Named Attribute at POINT domain returns 0 without it.
- **Map Range**: drag the To Max value to show how it controls max tube size.
- **Set Curve Radius**: the node that writes the per-point radius attribute
  that CurveToMesh actually reads.
- **Curve to Mesh**: toggle Fill Caps on/off to show open vs closed tube ends.
- **Merge by Distance**: zoom into a sphere vertex in the viewport and toggle
  the node off/on to show the raw coincident endpoints vs the welded junction.

## Tips
- Node Wrangler (Ctrl+Shift+Click) is excellent for previewing intermediate
  stages — especially comparing MeshToCurve output with CurveToMesh output.
- Show the Spreadsheet editor split below the GN editor while hovering over
  the Named Attribute node — it will display the `edge_sharpness` values at
  SPLINE domain, making the domain concept concrete.
- Use the overlay toggle (Viewport Overlays ▸ Statistics) to show face count
  difference between the source ico-sphere (80 faces) and the final swept
  mesh (several thousand) — illustrates the polygon budget cost of the technique.
