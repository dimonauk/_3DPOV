# GN Mesh Topology — Vertex Valence Heat Map (Blender 5.1)

Uses `GeometryNodeEdgesOfVertex.Total` to count adjacent edges per vertex
and maps the result to a colour gradient stored as a FLOAT_COLOR named attribute.
The result is a diagnostic heat map that shows where poles are before UV unwrap,
subdivision, or rigging.

## Colour key

| Colour | Valence | Vertex type |
|--------|---------|-------------|
| Blue   | 3       | N-pole — triangle fan, mesh-join seam |
| Green  | 4       | Ideal quad vertex |
| Yellow | 5       | E-pole — IcoSphere vertex, retopology star |
| Orange | 6       | Six-valence pole |
| Red    | 8       | UV sphere cap (valence = longitude segment count) |

## Files

| File | Purpose |
|------|---------|
| `blueprint.py` | Full scene construction — run in Text Editor or headless |
| `record.py` | 60-frame viewport render → `videos/.../viewport.mp4` |
| `SCREEN-RECORDING-NOTES.md` | OBS setup for `screen.mp4` |
| `vertex_valence_heat_map.blend` | Output blend (generated by blueprint.py) |
| `vertex_valence_heat_map.glb` | Export with custom `valence_col` attribute |

## Usage

```bash
# Build the blend + GLB
blender --background --python blueprint.py

# Render the viewport animation
blender vertex_valence_heat_map.blend --background --python record.py
```
