# CurveModifier + ArrayModifier (FIT_CURVE): Path-Following Ribbon
**Blender 5.1 | CC0 | Holoflow Studio**

Creates a flat ribbon accessory that follows a Bezier path using the classic
`ArrayModifier (FIT_CURVE) → CurveModifier` stack. Outputs a two-material
GLB ready for WebXR/VRM use.

## Files

| File | Purpose |
|------|---------|
| `blueprint.py` | Full headless scene builder — run in Blender Scripting workspace |
| `record.py` | Viewport animation render → `videos/.../viewport.mp4` |
| `SCREEN-RECORDING-NOTES.md` | OBS instructions for `screen.mp4` |
| `hf_ribbon_accessory.blend` | Generated by `blueprint.py` (not committed — run locally) |
| `hf_ribbon_accessory.glb` | Generated GLB (not committed — run locally) |

## Quick start

1. Open Blender 5.1 → Scripting workspace.
2. Open `blueprint.py` in the Text editor.
3. Click **Run Script**. The ribbon and path objects appear in the viewport.
4. Inspect the modifier stack on `hf_ribbon_accessory`: Weld → Array → Curve.
5. Run `record.py` to generate `viewport.mp4`.
6. Follow `SCREEN-RECORDING-NOTES.md` to record `screen.mp4`.

## Key parameters (top of blueprint.py)

| Constant | Default | Effect |
|----------|---------|--------|
| `TILE_LEN` | 0.022 m | Length of one profile tile; controls seam density |
| `RIBBON_W` | 0.038 m | Ribbon cross-section width |
| `RIBBON_T` | 0.003 m | Ribbon physical thickness |
| `WELD_DIST` | 0.0002 m | Tile-junction merge threshold |
| `DEFORM_AXIS` | `'POS_X'` | Must match tile long axis |

## Modifier stack explanation

```
Weld  → closes gaps between tile junctions (mode='ALL')
Array → repeats the profile tile; count = curve_length / TILE_LEN
Curve → bends the full array along the Bezier path tangent
```

Changing `TILE_LEN` alters both how many tiles fit and how visible the
junction seams are. Smaller tiles = smoother bends but higher triangle count.
