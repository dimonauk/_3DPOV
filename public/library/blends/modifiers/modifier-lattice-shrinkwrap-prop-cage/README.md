# Lattice + Shrinkwrap: Non-Destructive Prop Deformation Cage

**Blender 5.1 · CC0 · Holoflow Studio**

A shoulder pauldron is shaped and fitted to a body reference using two deform
modifiers in strict stack order — zero topology edits required.

## Files

| File | Purpose |
|------|---------|
| `blueprint.py` | Full Python scene: body reference, pauldron mesh, lattice cage, modifier stack, GLB export |
| `record.py` | Viewport animation recording — lattice pulse + 360° orbit |
| `SCREEN-RECORDING-NOTES.md` | OBS instructions for `screen.mp4` |
| `modifier_lattice_shrinkwrap_prop.blend` | Saved .blend (generated by blueprint.py) |
| `pauldron_prop.glb` | Fitted, applied-modifier GLB export |

## Modifier stack

```
prop_pauldron modifiers (top → bottom = evaluated first → last):

  [0] Lattice_Cage    — 3×2×3 CV cage  →  controls dome silhouette
  [1] Shrinkwrap_Body — NEAREST_SURFACEPOINT OUTSIDE 8mm  →  snaps equatorial ring to body
```

Swapping the order breaks the fit: Lattice overrides the surface snap.

## Quick start

```
1. Open Blender 5.1
2. Scripting workspace → Open → blueprint.py → Run Script
3. Select lattice_pauldron → Edit Mode → move top CVs to reshape dome
4. Select body_reference → S → X → 1.3: broader torso; prop refits automatically
5. See record.py for viewport animation
```
