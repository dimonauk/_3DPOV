## What to record (in order)

1. **Open Blender 5.1.** Briefly show the default scene to establish context.

2. **Open the Text Editor workspace.** Paste or open `blueprint.py`.  Point out
   the PARAMETERS block at the top — explain `GLARE_THRESHOLD = 0.80` (scene-
   linear, so values above 80% of 1 cd/m² bloom) and `GRAIN_STRENGTH = 0.035`
   (3.5% blend factor, equivalent to ~ISO 800 35mm film grain).

3. **Run the script** (Alt+P or Run Script button).  Switch to the 3D Viewport
   and show the scene: dark ground plane, chrome sphere with tight specular
   highlight, faceted purple gem, and key point light at 650 W.

4. **Switch to the Compositing workspace** (top header > Compositing tab or
   Shift+F3 in any area).  Enable **Use Nodes** if not already ticked.
   Walk the node tree left to right:
   - **Render Layers** → raw Cycles/EEVEE output (scene-linear HDR)
   - **Glare** (Fog Glow) — point at the `Threshold` and `Size` fields.
     Explain: Glare fires here because it needs the raw HDR values; if you
     moved it after the Tone Map the specular spike would already be clamped.
   - **Tone Map** (PhotoReceptor) — `Key = 0.18` matches the 18% grey card.
     Mention the two-pipeline rule: if AgX View Transform is active, remove
     this node to avoid double-tonemapping.
   - **Film Grain Image + Screen Mix** — the grain image was generated by the
     Python script at render resolution.  Screen blending avoids highlight
     clipping.  Note: it sits after the Tone Map so grain is in display-
     referred space (perceptually uniform).
   - **Lens Distortion** — barrel distortion `-0.03` plus dispersion `0.008`
     for lateral chromatic aberration.
   - **Ellipse Mask → Blur → Math (remap) → Multiply vignette chain** — explain
     why Multiply not Add-Black (hue preservation).
   - **Composite + Viewer** outputs.

5. **Press F12** to render one frame at 64 samples.  OIDN denoiser fires
   automatically.  Once the render completes, the Viewer node output shows the
   full cinematic grade.

6. **In the UV/Image Editor** (with the Viewer node active), zoom into the
   chrome sphere specular highlight — the Fog Glow bloom should be clearly
   visible as a soft halo around the bright spot.  Then zoom to a corner to
   show the vignette darkening.

7. **Compositor only — compare before/after:** Temporarily disable the Glare
   node (M to mute it), re-render, and show the flat version.  Re-enable and
   re-render to show the bloom.

8. **Demonstrate glare type switching:** Change `glare_type` from `FOG_GLOW`
   to `STREAKS` in the Glare node properties, re-render briefly to show the
   difference.  Revert to `FOG_GLOW` before finishing.

---

## Tips

- Use Ctrl+Shift+Click on any node to temporarily route it to the Viewer
  node — faster than rewiring for A/B comparisons.
- Zoom in on the node tree header fields when changing Glare type so they
  are legible on screen at 1080p.
- The F12 render at 64 samples should complete in 1–3 minutes on a mid-range
  GPU.  If your machine is slower, lower `RENDER_SAMPLES` to 16 in the
  PARAMETERS block and note in the narration that OIDN recovers quality.
- Record at least the node tree walkthrough even if you skip the live F12 —
  the compositor tree diagram is the core teaching asset.
