# Screen Recording Notes — EEVEE Next Volumetric Light Cone

Target file: `public/library/videos/lighting/eevee-next-volumetric-light-cone/screen.mp4`

---

## Setup (one-off)

1. Open **OBS Studio** (or Windows Game Bar: Win + G).
2. Add a **Window Capture** source.  Select **Blender 5.1** from the window list.
3. Resolution: **1920 × 1080**.  Frame rate: **30 fps**.  Audio: **off**.
4. Output format: **MP4**, encoder **H.264**, CRF **18** (high quality).
5. Set Output Path to `public/library/videos/lighting/eevee-next-volumetric-light-cone/screen.mp4`.

---

## What to record

The recording should show the full setup flow in Blender — roughly 4–6 minutes,
then trim to the most interesting 2–3 minutes for the final cut.

### Section 1 — World Volume setup (90 s)

1. Open `volumetric_light_cone.blend` (generated by `blueprint.py`).
2. **Start recording.**
3. Switch to **Shader Editor** (World context).  Show the Principled Volume node
   with Density and Anisotropy labelled.
4. In the 3D viewport (Solid mode), toggle **Z → Material Preview** to show the
   dark ambient.  Then toggle **Z → Rendered** (EEVEE Next) — the cones appear.
5. Slowly drag `Density` from **0.01 → 0.08** to show how density changes the
   beam visibility.  Return to `0.042`.
6. Drag `Anisotropy` from **0.0 → 0.9** to show the directional-scatter axis.
   Return to `0.60`.

### Section 2 — Volumetric shadow toggle (30 s)

1. Go to **Render Properties › Volumetrics**.
2. Uncheck **Volumetric Shadows** — the clean shaft disappears, replaced by
   a flat haze.  Recheck it.  This is the single biggest visual toggle.
3. Change **Tile Size** from **2px → 16px** to show the blocky artefact
   at low quality.  Return to **2px**.

### Section 3 — Bloom settings (30 s)

1. Go to **Render Properties › Bloom**.
2. Drag **Threshold** from `0.75 → 1.5` (bloom shrinks).
   Drag `Intensity` from `0.065 → 0.25` (bloom grows dramatically).
3. Return to tutorial values.

### Section 4 — Fake cone material (45 s)

1. Select **cone_amber** in the viewport.
2. Open **Shader Editor** (Object context) — show the Mix Shader (Transparent +
   Emission) with Fac = 0.11.
3. Switch to **GLTF Viewport** or note that this mesh exports cleanly to GLB.
4. Briefly toggle `blend_method` between **OPAQUE** and **BLEND** in Material
   Properties to show the transparency difference.

### Section 5 — Final orbit render playback (30 s)

1. Open the **Timeline** — frame range 1–240.
2. Set viewport to **Rendered** and press **Space** to play.
3. Camera orbits the scene showing both crossing beams from all angles.
4. **Stop recording.**
